# 历史参考资料归档

`non-floxml-reference.zip` 保存停止使用的输出格式资料，包括原格式规范、XSD、
示例以及相关旧文档。压缩包内按仓库原相对路径保存，并附 `manifest.json` 记录 SHA-256。

归档只用于历史查阅，不属于当前功能、生产依赖或验收契约。
非 FloXML 生产代码和专用测试已经移除，可从 Git 历史查阅。
归档来源基于整理前的仓库文件；后续文档只维护 FloXML。

旧预设审计和请求初值也保存在归档中，保留旧验证记录。
当前预设审计由 FloXML 验证工具重新生成，其他验证证据仍在 `docs/validation/`。
