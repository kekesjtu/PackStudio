# 原生 FloXML 研究参考

此目录中的五份厂商 XSD 来自 FloTHERM 2504 的 `XML_PLUGIN_SCHEMA`，
[bare-die.floxml](bare-die.floxml)供独立原生研究工具使用。

原生 PACK 导出证据位于 `flotherm_pack_data/template/<模板>/<扫参点>/`。
原生 FloXML 可用于核对矩形块几何、材料物性与总功率，其网格、监视点、非物理区域和辐射属性不属于产品输出范围。

产品输出契约为 [PackStudio XML](../packstudio/README.md)，生产导出不依赖厂商 XSD。
