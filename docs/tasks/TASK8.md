# TASK8：组件材料向导与分层模型树

**状态**：已完成（2026-07-30）

## 1. 背景

TASK7 的原生模板仍沿用了“右侧按结构组从完整材料库绑定材料”的交互。这既不符合引导式
建模流程，也允许芯片、塑封、基板等组件选择不适用材料。模型树只能对单块执行右键显隐，
无法按父组件或 Z 向结构层检查模型。数值字段的“验证区间”文案也容易被误解为求解验证。

## 2. 目标

- 材料选择进入组件对应的左侧引导步骤。
- 每个组件只显示生产模板显式声明的有限材料集合，后端执行同一白名单。
- 右侧改为“材料库”，支持浏览和编辑当前方案的材料覆盖属性，不再负责组件绑定。
- 模型树同时提供组件层级和 Layer 层级，并允许父节点递归显示/隐藏。
- 修复步骤切换后首个字段标签被滚动容器裁切的问题。
- 把“验证区间”改成语义准确的“允许范围”，说明它只是输入校验边界。

## 3. 实现

### 3.1 组件材料

- [x] 新增 `MaterialSelectionDefinition`，把组件组、向导步骤、默认材料和允许材料写入模板。
- [x] 八类模板逐项声明基板、芯片、粘接层、塑封、引线框、键合线等材料集合。
- [x] 前端材料字段写入 `material_assignments`，默认值不产生冗余覆盖。
- [x] 后端拒绝未知组件组和白名单外材料，不能通过直接 API 请求绕过。
- [x] BGA 和 Flip-chip 等效层继续由专用生成器确定材料，不开放会破坏等效物性的直接绑定。

### 3.2 材料库

- [x] 右侧标签改名为“材料库”，移除结构组绑定控件。
- [x] 可浏览材料 ID、各向同性/正交各向异性、导热率、密度、比热和来源。
- [x] 可编辑名称、颜色和热物性；修改以相同材料 ID 保存为当前方案覆盖值。
- [x] 内置材料定义不被改写，生成时当前方案覆盖值优先。

### 3.3 模型树与属性栏

- [x] 组件层级统计全部后代块，父节点显隐递归作用于子组件和块。
- [x] Layer 层级按相同 Z 起止面组织矩形块，支持整层显示/隐藏。
- [x] 保留块选择、单块显隐、只显示单块和恢复全部的右键操作。
- [x] 步骤切换时属性滚动区回到顶部，并增加足够顶部留白。
- [x] 数值字段显示“允许范围”，同时明确不代表仿真结果或精度验证。

### 3.4 兼容与验证

- [x] 恢复旧保存方案时过滤已删除字段和不再允许的材料绑定。
- [x] 后端测试覆盖八类材料 schema、白名单接受/拒绝和原生生成。
- [x] 前端测试覆盖材料向导、允许范围、材料属性覆盖和 Layer 显隐。
- [x] Ruff、ESLint、前端测试、后端测试和生产构建通过。

## 4. 可信度边界

- “允许范围”是生产模板输入契约，不等于该范围内所有多参数组合都完成 FloTHERM 或求解器
  回放验证。
- Layer 视图按矩形块的完整 Z 区间分组；它是结构检查层，不是求解器生成的网格层。
- 材料覆盖仅改变当前方案中相同稳定材料 ID 的属性，不修改 PackStudio 源码内置库。
