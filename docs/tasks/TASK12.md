# TASK12：FloTHERM PACK 风格向导与封装尺寸预设

**状态**：已完成

## 1. 背景

八类生产模板已经能生成与参考 FloXML 基准一致的默认矩形块，但左侧向导仍按 PackStudio
早期的通用组件分组组织，缺少 FloTHERM PACK 启动页中的标准外形尺寸入口，BGA 去球、中央
焊球和建模设置也集中在一个附加页面。QFP/SOIC 还把底部散热结构表述为“暴露焊盘”，与
目标工作流中的“散热焊盘与焊料”页面不一致。

## 2. 目标

- 参考 8 类已验证 UI、参数注册表和基准模型，按封装物理结构组织中文向导步骤。
- 所有封装默认使用固定 `standard_outline`；有封装外形标准的模板提供多个 JEDEC
  `Footprint` 尺寸，Bare Die 提供多个芯片尺寸预设。
- 选择尺寸预设后自动填入关联的总体尺寸、引脚/焊球数量和间距，仍允许用户逐项微调。
- `die_type` 固定为 `actual_type`，不显示 `thermal_type` 或只有一个值的选择器。
- 仅 BGA 焊球阵列显示正交各向异性等效层/离散建模选择。
- Flip-chip bumps 与可选 Bare Die bumps 固定为有厚度的正交各向异性等效层，不显示
  collapsed cuboid。
- QFP/SOIC 不显示 exposed-pad 选项，改为可选的散热焊盘与焊料，并生成两个对应实体。
- 生产运行继续不读取 `flotherm_pack_data`。

## 3. 实现清单

### 3.1 手写尺寸预设

- [x] 通用 schema 增加 `footprint` 控件、中文显示名、关联参数表和后端优先级。
- [x] 7 类 JEDEC 模板各提供默认基准和 2 个已捕获 FloXML 变体；Bare Die 提供 4 个尺寸。
- [x] 默认预设逐项保持原 FloXML 基准数值。
- [x] 显式尺寸覆盖在预设之后应用，允许对标准外形作工程微调。
- [x] 每个 JEDEC 预设显式声明芯片 X/Y；塑封体、承载台、阵列和引脚按各自差异设置，未使用
  全局比例缩放。

### 3.2 向导结构

- [x] 增加“概要”和“封装规格”，各模板步骤按参考 UI 的物理组件顺序排列。
- [x] Wirebond PBGA、FBGA、QFN、QFP、SOIC 的承载台、金属层、通孔、DAP、引线框等字段
  移至对应中文步骤。
- [x] BGA 焊球尺寸、焊球去除、中央焊球和建模方式分开呈现。
- [x] 建模页只显示真实可选项；固定行为不使用只读单选控件强调。
- [x] 材料字段不再提示“仅开放 N 种”，仍保持模板白名单与右侧材料属性编辑。

### 3.3 特殊结构

- [x] QFP/SOIC 将旧 `exposed_pad.*` 请求字段替换为 `thermal_land.*`。
- [x] 启用后分别生成散热焊盘和焊料矩形块，并提供各自有限材料选择。
- [x] Bare Die 增加可选凸点与底填充页面，统一调用有厚度的正交各向异性等效层。

## 4. 验证

- [x] 8 类共 25 个尺寸预设均能独立生成有效、无重叠模型。
- [x] 后端测试覆盖预设联动、手动覆盖优先级、固定 outline/die 行为和禁用 collapsed 模式。
- [x] 前端测试覆盖预设即时回填、切换预设清理旧联动覆盖和手动微调保留。
- [x] 后端 518 项、前端 14 项全量测试以及 Ruff、ESLint、TypeScript 和生产构建通过。
- [x] 自动测试逐类检查 8 类向导 schema；浏览器实测 Flip Chip CBGA、QFP、SOIC 的步骤顺序、
  JEDEC 联动、散热焊盘字段、滚动和窄栏显示，控制台无警告或错误。

## 5. 可信度边界

- 下拉项只包含默认基准与已捕获 FloXML 变体，不宣称复刻全部厂商目录。
- 默认项和非默认项的结构级尺寸均由对应 FloXML 回归保护；预设值仍只是后续步骤的默认值，
  用户可以独立微调芯片、塑封体、承载台和阵列参数。
- `flotherm_pack_data` 仅用于开发期证据核对和测试，生产代码不解析该目录。
