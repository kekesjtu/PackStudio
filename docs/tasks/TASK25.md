# TASK25 — FloXML 导出与 PACK 自动差异验证

状态：完成。日期：2026-10-17。

## 范围

在当前 PackageModel 上新增独立 FloTHERM FloXML 导出，并用真实 PACK 文件和本机
原生批量输出建立可重复的物理差异验证。按需求保留 PTA/ECXML 与现有建模取舍。

## 验收

- [x] 独立后端导出器、API、前端格式选择与下载，生产不依赖安装/参考资料
- [x] 八类模板的 XSD、几何、层级、材料、张量、密度、比热和热源保真检查
- [x] 382 份归档对照与本机新生成的 31 案，明确相同输入、来源、版本及文件指纹
- [x] 原始表达与归一化分区分别比较，不将原始重叠体积累加作为物理总量
- [x] 比较体积、质量、热容量、物性及功率；八类 2.5 W 案例守恒
- [x] 五类归因：取舍、有物理依据的不同实现、确认缺陷、原生风险、证据不足
- [x] 既有 F1/F2/F3 分类保留；Via 间隙、die/attach 重叠归为原生继承风险
- [x] 中文总结、机器结果、输入/输出/日志证据包、完整离线复跑及校验命令
- [x] 413 案离线复跑验证：412 份输出/物理指标一致，1 个已知拒绝一致
- [x] 前后端回归、构建、lint、提交说明及对应提交
