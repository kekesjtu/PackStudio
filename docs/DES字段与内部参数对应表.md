# PackStudio 内部字段—DES 键—PACK 组件及脚本属性名

对应结构化版本：[JSON](DES字段与内部参数对应表.json)。范围：PACK 2504；八类封装内部字段、DES、组件与 FloSCRIPT 属性。

## 约定

- 本表供人工核对与临时提取使用；生产应用只读取 runtime_data，不提供 DES 导入/导出，也不依赖此文档。JSON 与本文条目同源，每个 storage/key/family 表示一个语义条目，不保证一对一。
- DES 为 ZIP 内键|值文本，大小写敏感。DES 键、PACK 组件 name 和 property_name 各自独立。例如 cbga_fc Values[substrate.length] ↔ D ↔ name="packageSubstrate", property_name="substrateLengthD"。
- name=null 且 kind=wizard 表示 new_package/new_value 的向导属性，不是 modify_component 的 name。topCover 的 lid/plate/encapsulant 是子对象条件；FloSCRIPT name 只写 topCover。group_state、固定材料和展开行表不等同于标量脚本属性。
- 长度 mm，功率 W，覆盖率 %，计数为整数；金属层研究中间值由 m 乘 1000。yes/no、CHECKED/UNCHECKED、原生枚举在迁移阶段转换；运行预设只保存规范化值。
- 原生未指定及无数值的不适用项均保存 null；已保留数值的不适用分支仍保留数值。0、false、null 与字段不存在有不同含义；缺失的材料 assignment 不覆盖模板默认。完整原生状态属于研究记录，不是产品运行字段。
- 所有预设基于原生向导初始化和计算结果，而非直接用 DES 空串替代。七类封装 342 个预设共 416 分支；Bare Die 使用模板基线。四层仅在输入仍等于预设默认值时补入分支参数，用户覆盖优先；材料与 Bga 延续所选默认分支并接受用户覆盖。
- 四层创建 trace.solid_thickness 额外决定内层厚度，gap=(基板厚度−顶铜−底铜−2×内铜)/3；内层深度为顶铜+gap、顶铜+2×gap。普通层表编辑保留手填深度，生成器处理首末层贴面及外层铜厚联动。
- 金属层运行值始终为真实 JSON 数组。v1 方案文件与归档请求中的字符串层表只在输入边界转为数组；预设、编辑器、生成器和保存结果统一用数组。
- 脚本回放记录表示归档 script.xml 中有该 name/property_name；不代表每个数值或分支都验证完毕。原生记录属性与脚本可写性分别标记。未确认表示证据不足，不能作为提取绑定依据。
- DES 附件 .var2 为球位 CSV，.var3 为部分通孔名单；正式预设不自动读取附件。去球显式名单与 Ball Map 要求离散表达；各附件规则见 Bga 行。
