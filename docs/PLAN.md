# PackStudio 长期开发计划

## 1. 计划目标

本计划将 `requirements.md` 拆成可验收的增量阶段。主线始终是：输入封装参数，生成统一的
笛卡尔矩形块热模型，并可靠地传递给下游网格与求解模块。

## 2. 范围边界

本项目负责：

- 经典和先进 IC 封装模板；
- 引导式参数输入与校验；
- 矩形块几何、材料、热源和边界条件定义；
- 模型预览、检查和指定格式导出；
- 均匀 bump/via 层及复杂混合层的等效表达研究。

本项目不负责有限体积离散、数值求解和结果后处理。网格生成和模型降阶只有在单独需求评审
与 ADR 通过后才可进入范围。

## 3. 阶段规划

### 阶段 0：工程基础（TASK1）

**目标**：形成可重复的开发入口和清晰的技术路线。

任务：

- 完成前后端技术选型与架构决策；
- 建立 Python/conda、React/Vite、代码检查和测试脚手架；
- 解读 Flotherm PACK 的引导式建模工作流；
- 固化目录、开发说明和长期计划。

**退出标准**：新环境可按 README 启动前后端；最小测试、检查和构建全部通过。

### 阶段 1：统一模型与输出契约

**目标**：在开发具体模板前，定义唯一可信的中间模型。

任务：

- 明确坐标原点、轴方向、长度/温度/功率单位和数值精度；
- 定义 `Block`、`Material`、`HeatSource`、`BoundaryCondition`、`PackageModel`；
- 定义块的结构类型、稳定标识和块间关联；
- 盘点 `output_format/` 中 PTA XML 字段、命名空间、必填项和默认值；
- 建立 JSON Schema/OpenAPI 示例、PTA 黄金文件和往返/结构化对比测试；
- 记录无法从示例唯一推断的接口问题，交由下游负责人确认。

**退出标准**：领域模型能表达需求中的全部输出内容；代表性 PTA 示例可被解析、重建并通过
约定的兼容性比较。

### 阶段 2：裸芯片纵向切片 MVP

**目标**：以最简单模板贯通完整工作流，优先验证架构而非模板数量。

任务：

- 实现裸芯片模板的尺寸、材料、均匀/非均匀热源参数；
- 实现模板选择、分步表单、实时校验和错误定位；
- 实现轴对齐矩形块的三维显示、视角控制、选择和属性查看；
- 实现边界条件配置、模型检查和 PTA XML 导出；
- 增加前后端契约测试、领域单元测试和端到端冒烟测试。

**退出标准**：用户无需手改文件即可完成“选模板 → 输入 → 预览 → 检查 → 导出”，且导出
模型通过下游兼容性验证。

### 阶段 3：Flip Chip CBGA / BGA 模板

**目标**：覆盖参考产品中最有代表性的阵列封装工作流。

任务：

- 实现基板、芯片、flip-chip bumps、underfill、焊球、顶盖和嵌入式散热块；
- 支持全阵列、交错阵列、中央去除、中央焊球和自定义去球模式；
- 支持阵列离散矩形块与正交各向异性等效块两种表达；
- 增加几何约束：间距、包络、重叠、层叠顺序和材料完整性；
- 用手算小阵列和参考案例验证数量、坐标、总体尺寸和等效属性。

**退出标准**：至少一个 Flip Chip CBGA 参数集通过领域、预览、导出和下游导入的完整验收。

### 阶段 4：经典封装模板扩展

**目标**：建立可复用的模板组合机制并覆盖主要经典封装族。

建议顺序：

1. Wire-bond PBGA / Flip Chip PBGA；
2. QFN；
3. FBGA / FSBGA；
4. QFP、SOIC/SOP/TSOP/TSSOP 等周边引脚封装。

每个模板都必须具备参数字典、示意图、默认材料、校验规则、黄金模型和 PTA 导出用例。公共
的基板、芯片、焊球、引线、封装体等结构应组合复用，不复制生成逻辑。

**退出标准**：模板扩展不要求修改核心领域模型；每个封装族均有一个下游验证案例。

### 阶段 5：材料、模板库与交付质量

**目标**：从“能生成”提升到“可管理、可追溯、可长期使用”。

任务：

- 建立材料库，支持各向同性/正交各向异性导热、密度、比热、来源和适用温度；
- 建立模板元数据、版本、复制、自定义、导入导出和迁移机制；
- 增加模型摘要、缺失项检查、警告/错误分级和导出报告；
- 增加大阵列性能基准、跨平台测试和异常输入测试；
- 形成版本发布、示例模型和用户文档流程。

**退出标准**：模板与材料变更可追溯；旧模型有兼容/迁移策略；发布包能在目标机器复现。

### 阶段 6：均匀 bump / via 层等效模型

**目标**：用可验证的等效块降低大规模均匀阵列的模型复杂度。

任务：

- 明确串并联导热、体积分数和各向异性假设；
- 实现离散阵列与等效层的切换和适用性警告；
- 对不同填充率、长宽比和材料组合做参数扫描；
- 与离散模型或可信基准比较热阻误差，定义使用阈值。

**退出标准**：等效公式、假设、误差范围和回退策略均有文档与自动化验证。

### 阶段 7：RDL / interposer 混合层研究

**目标**：探索复杂走线层在矩形块框架内的工程等效表达。

任务：

- 调研铜密度图、方向性、分区均匀化和多尺度表达；
- 定义从版图统计到分区矩形块/各向异性材料的转换接口；
- 建立 RDL、interposer、TSV/via 的实验数据集和误差指标；
- 仅在验证后将研究原型纳入稳定模板。

**退出标准**：形成可复现基准、适用范围和“接受/继续研究/放弃”的技术决策。

## 4. 跨阶段质量门槛

- 所有输入在进入生成器前完成类型、范围、单位和相互约束校验；
- 领域规则以单元测试为主，导出以结构化比较和黄金文件为主；
- 模板必须验证块数量、坐标、尺寸、材料、热源、边界和稳定标识；
- 任何 `output_format/` 兼容性变化都需要单独评审；
- 单文件不超过 300 行，不保留调试语句或注释掉的死代码；
- 每阶段更新任务文档、用户文档、ADR 和提交说明。

## 5. 近期任务顺序

1. 完成 TASK1 工程基础；
2. 创建“统一领域模型与 PTA 契约盘点”任务；
3. 创建“裸芯片纵向切片 MVP”任务；
4. 在下游接口得到验证后，再进入 Flip Chip CBGA 模板开发。

此顺序用于尽早暴露单位、坐标和输出兼容性风险，避免在多个模板中重复返工。
