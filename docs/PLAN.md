# PackStudio 长期开发计划

## 1. 计划目标

本计划将 `requirements.md` 拆成可验收的增量阶段。主线始终是：输入封装参数，生成统一的
笛卡尔矩形块热模型，并可靠地传递给下游网格与求解模块。

## 2. 范围边界

本项目负责：

- 经典和先进 IC 封装模板；
- 引导式参数输入与校验；
- 矩形块几何、材料、热源和边界条件定义；
- 模型预览、检查和指定格式导出；
- 均匀 bump/via 层及复杂混合层的等效表达研究。

本项目不负责有限体积离散、数值求解和结果后处理。网格生成和模型降阶只有在单独需求评审
与 ADR 通过后才可进入范围。

## 3. 阶段规划

### 阶段 0：工程基础（TASK1）

**目标**：形成可重复的开发入口和清晰的技术路线。

任务：

- 完成前后端技术选型与架构决策；
- 建立 Python/conda、React/Vite、代码检查和测试脚手架；
- 解读 Flotherm PACK 的引导式建模工作流；
- 固化目录、开发说明和长期计划。

**退出标准**：新环境可按 README 启动前后端；最小测试、检查和构建全部通过。

### 阶段 1：统一模型与输出契约

**目标**：在开发具体模板前，定义唯一可信的中间模型。

任务：

- 明确坐标原点、轴方向、长度/温度/功率单位和数值精度；
- 定义 `Block`、`Material`、`HeatSource`、`BoundaryCondition`、`PackageModel`；
- 定义块的结构类型、稳定标识和块间关联；
- 盘点 `output_format/` 中 PTA XML 字段、命名空间、必填项和默认值；
- 建立 JSON Schema/OpenAPI 示例、PTA 黄金文件和往返/结构化对比测试；
- 记录无法从示例唯一推断的接口问题，交由下游负责人确认。

**退出标准**：领域模型能表达需求中的全部输出内容；代表性 PTA 示例可被解析、重建并通过
约定的兼容性比较。

### 阶段 2：裸芯片纵向切片 MVP

**目标**：以最简单模板贯通完整工作流，优先验证架构而非模板数量。

任务：

- 实现裸芯片模板的尺寸、材料、均匀/非均匀热源参数；
- 实现模板选择、分步表单、实时校验和错误定位；
- 实现轴对齐矩形块的三维显示、视角控制、选择和属性查看；
- 实现边界条件配置、模型检查和 PTA XML 导出；
- 增加前后端契约测试、领域单元测试和端到端冒烟测试。

**退出标准**：用户无需手改文件即可完成“选模板 → 输入 → 预览 → 检查 → 导出”，且导出
模型通过下游兼容性验证。

### 阶段 3：Flip Chip CBGA / BGA 模板

**状态**：已完成（TASK2，2026-07-11；TASK3/TASK4 扩展，2026-07-12；TASK5 扩展，
2026-07-14）。实现说明见
[Flip Chip CBGA / BGA 模板](templates/flip-chip-cbga.md)，关键模型与精简 PTA 契约见
[ADR-0002](decisions/0002-Flip-Chip-CBGA-模型与-PTA-导出约定.md)，交互、材料绑定和塑封
表达见 [ADR-0003](decisions/0003-TASK3-交互材料与塑封表达.md)，仿真就绪预设见
[ADR-0004](decisions/0004-TASK4-仿真就绪导出约定.md)，组合焊球、直接换热系数和尺寸预设见
[ADR-0005](decisions/0005-TASK5-组合焊球与尺寸预设.md)。

**目标**：覆盖参考产品中最有代表性的阵列封装工作流。

任务：

- 实现基板、芯片、倒装芯片凸点、underfill、焊球、顶盖和嵌入式散热块；
- 默认使用规则全阵列，并支持中央去球、中央焊球和附加单元去球独立组合；
- 支持阵列离散矩形块与正交各向异性等效块两种表达；
- 增加几何约束：间距、包络、重叠、层叠顺序和材料完整性；
- 用手算小阵列和参考案例验证数量、坐标、总体尺寸和等效属性。
- 以四栏工作区组织参数、预览、材料库和模型树，并支持预览块显隐；
- 增加共享材料定义和可选塑封体，保证预览、领域模型和 PTA 分层一致。
- 固定倒装凸点的各向异性等效表达，并用静态空气补齐无 underfill 的 BGA 层；
- 输出层级最大网格尺寸、默认自然对流以及 PCB 侧和顶部直接换热系数；
- 在汇总页提供常用 CBGAFC 外形预设和参数保存，在材料库提供可调水平分隔条；
- 根据顶部散热结构自动选择淹没式塑封盖层或裸露芯片接触面。

**退出标准**：至少一个 Flip Chip CBGA 参数集通过领域、预览、导出和下游导入的完整验收。

### 阶段 4：经典封装模板扩展

**状态**：已完成（TASK6，2026-07-29）。八类参考模板及证据边界见
[ADR-0006](decisions/0006-TASK6-八类证据驱动模板.md)。

**目标**：建立可复用的模板组合机制并覆盖主要经典封装族。

已交付：

1. Wirebond PBGA、Flip Chip PBGA；
2. QFN；
3. FBGA / FSBGA；
4. QFP family、SOIC family；
5. Bare Die 与经基准证据全面复核的 Flip Chip CBGA。

每个模板都必须具备参数字典、示意图、默认材料、校验规则、黄金模型和 PTA 导出用例。公共
的材料、矩形分区、特殊层、热源和边界通过生产基础设施复用，具体几何保留在各模板模块中。

**退出标准**：模板扩展未修改核心领域模型；8 类基准均有生成与 PTA 导出自动回归。
下游 PTA GUI 导入、网格和求解仍作为交付前人工验收。

### 阶段 4.1：生产模板运行时解耦

**状态**：已完成（TASK7，2026-07-29）。决策见
[ADR-0007](decisions/0007-TASK7-生产模板与参考数据解耦.md)。

**目标**：让八类模板可以脱离开发期参考资料独立部署和运行。

完成内容：

- 删除运行时 JSON/FloXML repository、parser 和 variation patch；
- 在八个生产模块中显式实现字段、范围、条件和几何规则；
- 内置稳定材料 ID 和物性，不复用 FloXML 哈希标识；
- schema v2 和主 API 仅返回原生实现；
- 通过禁止文件读取的自动测试证明八类生成和导出不依赖 `flotherm_pack_data`。

**退出标准**：部署包删除参考目录后，八类生成、材料配置和 PTA 导出仍通过。

### 阶段 4.2：组件材料与分层检查

**状态**：已完成（TASK8，2026-07-30）。决策见
[ADR-0008](decisions/0008-TASK8-组件材料与模型树层级.md)。

**目标**：收紧材料适用范围，并让几何模型可以按组件和结构层检查。

完成内容：

- 八类模板显式声明每个组件允许选择的有限材料集合，前后端执行同一白名单；
- 材料选择进入对应引导步骤，右侧材料库用于浏览和编辑当前方案物性；
- 模型树保持单一父子结构，父节点支持折叠/展开与后代块递归显隐；
- 输入上下限改称“允许范围”，不再暗示求解验证；
- 属性栏切换步骤时复位滚动位置，修复首个字段标签裁切。

**退出标准**：任意材料不能绕过 API 白名单；材料属性覆盖、父节点折叠与递归显隐均有
自动化回归。

### 阶段 4.3：手写模板 FloXML 保真纠偏

**状态**：已完成（TASK9，2026-07-30）。决策见
[ADR-0009](decisions/0009-TASK9-手写模板与FloXML保真.md)。

**目标**：在保持生产运行不读取参考目录的前提下，把八类模板逐项纠正为已验证 FloXML
事实的手写转录，而不是猜测性几何。

完成内容：

- 八类默认原始 cuboid 的数量、原点和尺寸逐块匹配基准；
- 默认材料逐块核对，并保留规定的 Flip-chip 正交各向异性特例；
- 320 个已映射数值单变量、6 个顶盖分支和 48 个顶盖数值变体形成开发期黄金回归；
- Flip-chip 顶盖、QFN DAP、QFP tie bar、SOIC 键合块和两类 PBGA via 联动完成纠偏；
- 最终输出继续使用 TASK5 的确定性矩形差集，且运行时独立性测试保持通过。

**退出标准**：开发期参考对照与部署期无参考目录运行两类测试同时通过。

### 阶段 4.4：模板分类与死代码治理

**状态**：已完成（TASK10，2026-07-30）。决策见
[ADR-0010](decisions/0010-TASK10-封装模板分类与死代码治理.md)。

**目标**：不改变八类模型结果的前提下，按封装物理类别整理模板代码，并删除已被通用向导
替代的不可达前端实现。

完成内容：

- 生产模板拆分为 `core`、`bga`、`flip_chip`、`leadframe` 和 `bare_die`；
- BGA 与 Flip-chip 层构造分离，模板库根目录只保留 catalog；
- 通用前端模型编辑组件迁至 `model-editor`；
- 删除旧单模板工作区、属性面板、材料流程、专属测试和无引用样式；
- 增加八类模块导入与根目录结构约束，完整保真回归保持通过。

**退出标准**：引用审计无未解释死代码，八类模板分类可导入且全量测试通过。

### 阶段 4.5：PTA 根级布尔块压缩

**状态**：已完成（TASK11，2026-07-31）。决策见
[ADR-0011](decisions/0011-TASK11-PTA根级布尔块导出.md)。

**目标**：利用 PTA 根级 Blocks 的独立 Z 挤出和 `Add_sub` 矩形布尔操作，减少
TASK5 无重叠差集产生的零散求解器实体。

完成内容：

- 增加矩形布尔操作和独立 Z 布尔块领域对象；
- 同一逻辑源按自身 Z 段恢复精确二维占用，自动选择多个加矩形或外框减空区；
- 高碎片模板使用 Block Mode，简单模板保留 Layer Mode；
- QFN 强制 Layer 导出的 XML 实体从 3747 降至 318，塑封从旧路径的 3421 个 XML
  实体降至 5 个布尔实体；
- 五类高碎片模板逐材料体积一致，既有 Layer Mode 回归保持通过。

**退出标准**：自动化几何等价和格式测试通过；目标 PTA GUI 导入、网格和求解列为交付人工
验收项。

### 阶段 5：材料、模板库与交付质量

**目标**：从“能生成”提升到“可管理、可追溯、可长期使用”。

任务：

- 建立材料库，支持各向同性/正交各向异性导热、密度、比热、来源和适用温度；
- 建立模板元数据、版本、复制、自定义、导入导出和迁移机制；
- 增加模型摘要、缺失项检查、警告/错误分级和导出报告；
- 增加大阵列性能基准、跨平台测试和异常输入测试；
- 形成版本发布、示例模型和用户文档流程。

**退出标准**：模板与材料变更可追溯；旧模型有兼容/迁移策略；发布包能在目标机器复现。

### 阶段 6：均匀 bump / via 层等效模型

**目标**：用可验证的等效块降低大规模均匀阵列的模型复杂度。

任务：

- 明确串并联导热、体积分数和各向异性假设；
- 实现离散阵列与等效层的切换和适用性警告；
- 对不同填充率、长宽比和材料组合做参数扫描；
- 与离散模型或可信基准比较热阻误差，定义使用阈值。

**退出标准**：等效公式、假设、误差范围和回退策略均有文档与自动化验证。

### 阶段 7：RDL / interposer 混合层研究

**目标**：探索复杂走线层在矩形块框架内的工程等效表达。

任务：

- 调研铜密度图、方向性、分区均匀化和多尺度表达；
- 定义从版图统计到分区矩形块/各向异性材料的转换接口；
- 建立 RDL、interposer、TSV/via 的实验数据集和误差指标；
- 仅在验证后将研究原型纳入稳定模板。

**退出标准**：形成可复现基准、适用范围和“接受/继续研究/放弃”的技术决策。

## 4. 跨阶段质量门槛

- 所有输入在进入生成器前完成类型、范围、单位和相互约束校验；
- 领域规则以单元测试为主，导出以结构化比较和黄金文件为主；
- 模板必须验证块数量、坐标、尺寸、材料、热源、边界和稳定标识；
- 任何 `output_format/` 兼容性变化都需要单独评审；
- 单文件不超过 300 行，不保留调试语句或注释掉的死代码；
- 每阶段更新任务文档、用户文档、ADR 和提交说明。

## 5. 近期任务顺序

1. 使用 PTA GUI 对 8 类 FloXML 保真原生模板代表导出执行导入、网格生成和稳态求解验收；
2. 对根级 Block Mode 代表模型增加导入后实体数和网格性能基准；
3. 对前端三维预览和材料编辑器做按需加载，降低生产主 chunk；
4. 为模板与材料补充用户自定义、版本迁移、来源和适用温度管理；
5. 为未经组合回放的多参数组合增加摘要、警告和可追溯导出报告。

该顺序先完成下游兼容性与性能验收，再进入模板/材料长期管理。
