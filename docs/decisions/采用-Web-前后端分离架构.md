# Web 前后端分离架构

## 决策

React / TypeScript 组织参数向导与三维界面，本地 Python / FastAPI 服务负责
参数校验、几何生成、等效物性与 FloXML 输出，两者通过 HTTP / JSON 交换数据。
领域模型、模板生成器和导出器作为独立模块维护。
浏览器模式与独立窗口复用同一套前端产物和后端服务。

## 依据

交互界面与建模计算分别维护，Python 负责计算，浏览器三维技术负责交互显示。
两种运行方式共享封装建模实现。

## 运行与维护

本地启动和分发管理后端生命周期、端口与静态资源。
模块职责见[技术栈](../tech_stack.md)，运行与验证命令见[开发说明](../development.md)。
