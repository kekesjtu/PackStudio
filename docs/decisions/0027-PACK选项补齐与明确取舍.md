# ADR 27：PACK 选项补齐与明确取舍

日期：2026-10-21；状态：接受（用户明确指定范围）。

## 明确取舍

- 八类模板不实现非均匀芯片热源及其编辑器。总功率按体积分配，保持相同体热源密度。
- PQFP / SOP 不实现自定义引线框覆盖率开关或百分比。继续按当前 B/e 重算等效物性。
- QFN 的热通孔启用采用离散等面积矩形，不扩展 lumped 表达；延续 requirements §2.1
  仅 BGA 阵列提供表达切换的规则。芯片数组通孔仍随焊球行列与间距布局。

## 补齐范围

- WB 背面扩散片与底层走线开孔：恢复 29 个原生已启用预设的长宽厚、开孔与材料。
  禁用预设的编辑初值取 `PBGA_192_17X17mm` 有效记录，不能标作禁用预设的原生默认值。
  扩散片从基板底面向上，先占据体积，再裁剪走线、过孔及介质。长度/宽度须在基板内，
  厚度不得超过基板厚度；开口须在走线外框内，避免生成零尺寸环。
- 扩散片选材提供 Copper (Pure) 与内建 Alloys (Leadframe)，支持当前方案物性覆盖。
- Bare Die 增加 GaAs 与内建 Resins 底填候选；保留既有材料。截图中的 No Attachment、
  Material/Material1 等临时项没有独立内建物性，不加入组件候选。
- WB、Chip Array、QFN 共用热通孔去孔配置。显式坐标去重后与居中区域取并集；允许
  全部去除，保持未删除孔的物性，禁用去孔时保留完整阵列。禁用通孔时保留编辑配置。
- QFN 空心孔物性按铜的镀层面积比例计算；孔体积为圆孔等面积矩形乘孔长。
  启用初值来自已存档单变量脚本，而不是当前 ignored 分支未指定的值。

## 限制

本次只关闭审查中的 G01、G03、G06、G09、G10、G11 与 Bare Die 的 R01 候选差异。
G02、G04、G05、G07、G08、其他模板的材料候选差异及 R02 元数据不在本次实现范围。
