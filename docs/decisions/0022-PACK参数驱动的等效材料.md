# ADR22 — PACK 参数驱动的等效材料

日期：2026-10-12；状态：采用。

2026-10-17 补充：后续审查发现等效引线/连筋、bump/BGA 物性覆盖及 WB 铜层仍有链路缺口，
现按 [ADR26](0026-等效材料与QFP高差缺陷修复.md) 补齐；原有验证结果保留其历史覆盖范围。

## 背景

11个 implemented 参数虽可编辑，却没有生成效果。PACK 2504 DLL 与22个既有 FloXML
单变量用例表明，这些参数主要改变等效材料；原固定家族张量不能承载联动。
生成器还会把组件的纯金属选材覆盖到等效 cuboid 上，抹掉计算效果。

## 决策

- 在生成阶段按保留分支的显式 PACK 公式重算键合线、过孔及承载台材料。
- 组件选材作为组分输入；计算后的等效材料用于物理块，纯金属不再覆盖等效张量。
- SOP tie bar 与 die flag 虽共用原始材料 ID，但按组件范围分别应用绑定。
- 用户物理材料编辑参与计算；用户显式覆盖生成后等效材料时保留其优先级。
- 从独立预设库读取过孔金属与 filledVias 状态；不引入生产 DLL 或研究目录依赖。
- 保留审核 cuboid 几何包络、项目去球/中央区规则、温度参考张量与现有输出契约。
- 保留 PQFP 每侧线数取整以及 SOP 默认长度字段没有输出效果的原生规则。

公式、RVA、证据与覆盖限制见 [联动记录](../research/pack-material-couplings.md)。
模板中的旧张量保留为审核基线/命名资料；它们不再替代上述生产计算结果。
