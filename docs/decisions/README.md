## 文档维护

每项重要决策使用一个按主题命名的文件，描述设计约定、依据、适用范围与实现对照。
正文采用一般现在时和肯定式陈述，系统现状与决策范围分别表述。
用户明确指定的功能排除项在对应决策中按其确认内容记录。
参数细节由运行数据文档维护，输出字段与单位由格式契约维护，操作命令由开发说明维护。
