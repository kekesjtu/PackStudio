# 技术决策记录 (ADR)

在这个目录下记录重要技术决策，**仅仅记录重要决策**，每个决策一个文件。

## 命名规则

`NNNN-<简短描述>.md`，如 `0001-选择-React-作为前端框架.md`。

## 决策模板

```markdown
# ADR-NNNN: <决策标题>

## 日期
YYYY-MM-DD

## 背景
<为什么需要做这个决策？当前面临什么问题？>

## 决策
<我们决定做什么？>

## 备选方案
| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| A | ... | ... |
| B | ... | ... |

## 理由
<为什么选择这个方案而非其他？>

```
