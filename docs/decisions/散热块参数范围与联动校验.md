# 散热块参数范围与联动校验

## 决策

散热块的数值参数以 `0` 为定义下限，并在输入阶段统一检查散热块字段之间的几何自洽关系。
越界与关系冲突都作为输入阶段错误报告，问题条目定位到相关参数，并阻止模型生成与导出。

## 字段范围

`cbga_fc`、`pbga_fc`、`pbga_wb` 的散热块长度、宽度、厚度、顶部直径、外轮廓长度、外轮廓宽度、顶部台阶高度与支脚间隙统一定义 `minimum: 0`。
数值框右侧显示 `≥0`，字段范围与生成前的输入校验共用同一份定义。

## 联动校验

适用模板为 `cbga_fc`、`pbga_fc`、`pbga_wb`，规则依据为散热块几何块的构造方式。

| 条件 | 代码 |
| --- | --- |
| 散热块长度、宽度、厚度与顶部直径大于 `0` | `input.slug.size` |
| 外轮廓长度大于本体长度，外轮廓宽度大于本体宽度 | `input.slug.foot` |
| 顶部圆盘等效边长 $\sqrt{\pi}\,d/2$ 小于本体长度与宽度 | `input.slug.plate` |
| 两倍厚度小于本体长度与宽度 | `input.slug.wall` |
| 芯片长度、宽度小于腔体开口（本体边长减去两倍厚度） | `input.slug.die` |
| 厚度、顶部台阶高度与支脚间隙之和小于可用塑封高度 | `input.slug.height` |
| 启用支脚粘接层时支脚间隙大于 `0` | `input.slug.adhesive` |

可用塑封高度按顶部结构取值：`cover.flush` 为真时取 `bumps.height + die.thickness`，否则取 `cover.thickness`；`pbga_wb` 取 `encapsulant.thickness - solder_mask.thickness`。
支脚由本体外轮廓四侧向外扩展，侧壁由本体轮廓减去厚度构建，顶部圆盘与水平环共用本体方框，因此对应尺寸必须保留正体积。
腔体开口为本体边长减去两倍侧壁厚度，芯片位于腔体内，芯片与散热块共用中心；芯片超出腔体开口即与侧壁重叠，因此在输入阶段报告。
胶层厚度等于支脚间隙，间隙为零时胶层块无体积。

## 验收标准

- 越界或关系冲突在参数向导中即可见，问题条目可定位到对应字段，生成与导出保持禁用。
- 满足上述关系的散热块参数可正常生成、预览并导出，块尺寸与位置遵循[FC Slug 支脚与胶层纵向位置](原生bug-FC-Slug支脚与胶层纵向位置.md)。
