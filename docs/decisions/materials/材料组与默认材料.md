# 材料组与默认材料

组件选材采用“材料组 + 组内材料”联动。按材料库分类筛选适用于该组件的候选，切组时同时选择组内有效材料，所选材料进入当前方案。

材料库按相同分类顺序展示全部材料，缺少分类时归入 Others。组标题显示数量及方框加减号，默认折叠，各组独立展开。点击材料在下方打开属性栏，再次点击当前材料时取消选择并收起属性栏，保持分组展开状态。

同名材料的展示代表依次优先采用已分配材料、方案自定义材料、模型材料，再按稳定 ID 选取。同一 ID 的有效物性依次以方案覆盖、模型材料、材料库为准。

## 默认选材

组件及其条件分支均有明确的默认材料组和默认材料。PACK 已指定有效材料时沿用该材料。缺省或为 No Attachment 时，预设提供对应组件的默认材料，材料组取默认材料所在分类。Bare Die 的凸点焊料和底填材料由内置预设提供。

| 组件 | 默认材料组 | 默认材料 |
| --- | --- | --- |
| FC CBGA/PBGA、Wirebond PBGA 散热块 | Metals | Copper (Pure) |
| FC CBGA/PBGA、Wirebond PBGA 散热块支脚粘接层 | Attachment Materials | Stiffener Adhesive (Typical) |
| FC PBGA 上下增层介质 | Substrate Dielectrics | BT |
| PQFP、SOP、QFN 板侧散热焊盘 | Metals | Copper (Pure) |
| PQFP、SOP 散热焊盘焊料 | Alloys (Solders) | Solder (Sn63/Pb37) |
