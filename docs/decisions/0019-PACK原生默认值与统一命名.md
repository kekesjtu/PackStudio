# ADR19：PACK 原生默认值、材料名称与封装命名

日期：2026-10-11；状态：采用。

旧适配从不完整 DES 文本继承家族初值，并保留七个 FloXML 基线，导致安装界面与项目默认值
存在差异。完整原生库已经保存初始化后的参数，应成为支持字段的唯一 PACK 来源。

使用版本化 `pack_bindings.json` 的明确路径投影已实现字段。预设选材按 PACK 名称解析
独立材料库；禁止把源空值当零或完整默认值。原生未启用字段的编辑初值显式保存为
`editor_default`，审计记录范围。完整四层及其他未实现分支留在库中，界面保留现有能力。

显示名称、顺序采用 PACK 八种 Package Types；生产模块、JSON、字段前缀、API、模型和
下载文件使用一致 ID。删除旧别名路由；保存空间升为 v3，不迁移旧保存方案。历史 FloXML
比对改用明确的原始输入夹具，继续检验当时捕获的几何，不约束当前默认值。

当前材料领域和输出契约使用常量张量。温度依赖材料按原生参考温度投影，材料来源明确
标注，完整关系保留在材料库中。键合线、金属层等仍采用项目审核等效模型，不能据此宣称
全部 PACK 模型保真。

删除重复转录、旧聚合快照、被替代工具。保留 DES 来源证据、FloXML 对照、版本守卫的
提取工具和可复现生成/导出审计；运行包不含研究目录和工具。
