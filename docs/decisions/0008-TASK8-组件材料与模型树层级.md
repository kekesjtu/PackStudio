# ADR-0008：TASK8 组件材料与模型树层级

## 日期

2026-07-30

## 状态

已采纳。本 ADR 收紧 ADR-0007 中“按结构组重新绑定材料”的范围：绑定入口移到组件向导，
且只接受模板声明的候选材料；材料库仍允许为当前方案编辑材料属性。

## 背景

完整材料库不是组件材料候选列表。允许任意结构组绑定任意材料，会让芯片选择焊料、塑封选择
铜等无物理意义组合进入生成器，也使模板定义无法完整表达其材料假设。另一方面，用户仍需要
查看和调整导热率、密度、比热等物性。模型检查也需要在单块以外提供组件和结构层两种尺度。

## 决策

### 1. 选择与编辑分离

- 左侧组件步骤负责材料选择，候选材料由生产模板的 `MaterialSelectionDefinition` 声明。
- 右侧材料库负责浏览和编辑物性，不显示组件绑定控件。
- 材料编辑以稳定材料 ID 写入当前请求的 `custom_materials`；内置库保持不可变。

### 2. 白名单属于后端契约

- schema 为材料字段返回组件组 ID、默认材料和有限选项。
- 前端只渲染这些选项，后端再次校验组件组和材料 ID。
- 不为 BGA 焊球和 Flip-chip bumps + underfill 开放普通组绑定，以免用单一材料覆盖动态计算的
  空气/焊料分区或正交各向异性等效材料。

### 3. 两种模型树层级

- 组件层级使用 `ModelGroup.parent_id`，父节点操作覆盖全部后代块。
- Layer 层级按块的 `(origin.z, max_z)` 区间分组，自上而下显示并支持整层显隐。
- Layer 是几何结构层，不宣称等同于 PTA 网格或求解器离散层。

### 4. 输入边界用词

- schema 单独返回 `minimum` 和 `maximum`，不再从一般的 `supported_values` 猜测区间。
- 前端使用“允许范围”，并说明其作用是阻止生产模板不能处理的输入。
- 不使用“验证区间”，避免暗示所有范围内组合已经完成热仿真验证。

## 结果

- 模板材料假设可以审查、测试并随代码版本稳定演进。
- 用户仍能针对当前设计校准物性，但无法借助普通 UI 或 API 绕过组件材料适用范围。
- 大模型可按组件或 Z 向结构层快速定位和显隐。
- 旧方案中的任意材料绑定在恢复时被过滤，避免迁移后无法进入工作区。
