# ADR-0003：TASK3 交互、材料绑定与塑封表达

## 日期

2026-07-12

## 背景

Flip Chip CBGA 的参数、预览和模型树集中在三栏页面后，结构数量增加会使属性定位和模型检查
变得困难。材料物性散落在各结构参数中还会产生同名材料副本。新增塑封体时，也必须在矩形块
约束下避让芯片并保持 PTA 的连续 Z 分层。

## 决策

### 1. 四栏工作区

- 从左到右固定为结构导航、当前结构属性、三维预览、材料库/模型树检查器。
- 结构导航只切换属性上下文，不改变参数值或当前模型。
- 属性栏与三维预览之间使用可访问的分隔条调宽，支持指针拖动和键盘方向键。
- 小屏幕按属性编辑优先顺序折叠为单列，不维持不可用的四栏最小宽度。

### 2. 以材料 ID 维护共享物性

- 名称、颜色、`kx/ky/kz`、密度和比热均属于材料定义，结构参数只保存所选材料。
- 前端材料库从当前模板参数中的材料按 ID 去重；修改一个定义时，将更新同步到同 ID 的全部
  结构引用。
- 生成请求仍使用嵌入式材料对象，以保持现有 API 契约和后端校验；后端继续按 ID 注册并拒绝
  同 ID 不同物性的冲突。

### 3. 模型显隐属于视图状态

- 模型树块菜单提供“隐藏这个模型”“只显示这个模型”和“显示全部模型”。
- 隐藏集合只由浏览器工作区持有，三维预览据此过滤块。
- 生成领域模型、热源、边界条件和 PTA 导出均不读取隐藏集合，防止检查操作意外修改工程数据。

### 4. 塑封体使用双层矩形环

- 塑封外包络必须在 X/Y 两个方向严格大于芯片，并完全位于基板包络内。
- 内部以芯片长宽形成避让区，环形区域拆为前、后、左、右四个不重叠矩形块。
- 相同环形平面分别复用凸块层和芯片层的 Z 区间，因此启用后生成 8 个块，但不增加新的 Z
  层，也不会破坏 PTA 连续层约束。
- 塑封默认关闭。没有顶盖、热界面层或散热块时，启用的顶面对流同时作用于芯片与四个塑封
  上层块的顶面。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 每个结构保存独立材料副本 | 编辑共享材料时容易遗漏引用，未采用 |
| 模型树隐藏直接删除块 | 会让预览操作改变导出数据，未采用 |
| 用单个实心块表示塑封 | 与芯片和凸块区域产生正体积重叠，未采用 |
| 仅在芯片高度生成一层塑封 | 无法表达参考模型中覆盖完整芯片堆叠的塑封体，未采用 |

## 结果

- UI 状态、模板参数和生成领域模型的职责边界清晰；材料修改与模型显隐具有确定行为。
- 塑封体遵守轴对齐矩形块、无正体积重叠和 PTA 连续分层约束。
- 后续如果 API 改为独立材料表，需要提供版本化迁移；在此之前保持嵌入式请求格式兼容。
