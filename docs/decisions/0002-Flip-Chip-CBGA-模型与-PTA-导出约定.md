# ADR-0002：Flip Chip CBGA 模型与 PTA 导出约定

## 日期

2026-07-11

## 背景

Flip Chip CBGA 同时包含规则阵列、不规则去球区域、顶层结构、热源和下游 PTA XML。
如果坐标、阵列占位范围和等效物性没有统一定义，前端预览、领域校验与导出结果会发生偏差。
此外，PTA 工程中的网格和求解结果由 PTA 求解阶段生成，不应由 PackStudio 伪造或复制。

## 决策

### 1. 统一领域坐标与单位

- 领域模型和 API 均使用 mm。
- 原点位于基板底面中心，X 为封装长度方向，Y 为封装宽度方向，Z 向封装顶部为正。
- 基板底面为 `z = 0`；BGA 焊球位于负 Z；凸块、芯片和顶层结构位于正 Z。
- PTA 的层坐标不能从负值开始，因此导出时仅对 Z 整体平移，使最低层从 0 开始；X/Y
  和各层相对位置不变。

### 2. 阵列单元与离散表达

- 每个阵列单元的占位尺寸为 `pitch_x × pitch_y`。
- 物理圆柱焊点在笛卡尔块模型中替换为等体积方柱，方柱边长为 `sqrt(pi) × radius`。
- 离散模式可用四个互不重叠的矩形块补齐每个单元中的 underfill / 基体材料。
- 接触面允许相切，任何正体积重叠均视为错误。

### 3. 各向异性等效层

采用任务给定推导文档第 4 节的串并联热阻模型。填充率和等效纵向导热率为：

```text
f  = pi × r² / (px × py)
kz = f × kb,z + (1 - f) × ku,z
```

X/Y 方向分别按对应方向的 pitch 计算串并联热阻。等效密度按体积分数混合；等效比热按
体积热容守恒后除以等效密度。这样同时保持质量和总热容。

### 4. 非均匀阵列分区

- 全阵列形成一个等效矩形块。
- 交错阵列按行形成等效矩形块，每相邻行相差半个 X pitch。
- 中央去球将外围均匀区域拆成四个无重叠矩形；中央区域不建模或填充均匀基体材料。
- 中央焊球将外围拆成四个矩形，并将中央均匀阵列作为第五个独立矩形和模型树子组。
- 自定义去球使用确定性的矩形分割覆盖保留单元，空缺区域同样可不建模或填充基体材料。

### 5. 精简 PTA XML

PackStudio 只导出 PTA 打开模型所需的输入数据：

- 分层矩形块几何；
- 各向同性或正交各向异性材料、密度和比热；
- 芯片体热源；
- 已启用的温度、热流或对流边界；
- 稳态热传递研究的基础配置。

以下数据明确不导出：

- `Mesh*` 网格字段和网格实体；
- `Results`、`LayerPBResults`、`ThermalMaskResults` 等求解结果；
- 求解器在计算过程中生成的派生场数据。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 每个焊点直接输出圆柱或球体 | 不符合当前“轴对齐矩形块”领域约束，未采用 |
| 非均匀阵列整体使用单一等效块 | 会错误均化中央去球/中央焊球区域，未采用 |
| 在 PackStudio 中预生成 PTA 网格 | 网格参数属于下游求解流程，且用户确认 PTA 可在无网格数据时打开，未采用 |
| 复制空的结果节点以贴近示例文件 | 容易混淆输入与求解产物，未采用 |

## 结果

- JSON 模型是前端预览与后端生成器之间的稳定协议，PTA XML 是下游分发格式。
- 导出器必须通过“无网格、无结果”结构测试，并与 `output_format/cases_for_PTA/` 的
  DataContract 命名空间和输入节点保持兼容。
- 如果后续目标 PTA 版本要求新的输入字段，应以独立兼容性变更更新契约和测试，不应恢复
  求解结果数据。
