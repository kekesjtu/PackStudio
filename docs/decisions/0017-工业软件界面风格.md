# ADR-0017：工业软件界面风格

日期：2026-09-30。状态：已采用。

用户要求保留已决定的功能和分区，使界面更接近 FloTHERM 类工业软件的风格。
采用深蓝灰标题栏、浅灰工具面板、细边框、紧凑文字和方角控件，降低卡片式留白与圆角。
风格通过独立 MUI theme 与 CSS 实现，不复制其他软件的功能或更改建模规则。

保留顶部模板选择、左侧引导、参数面板、三维视图和右侧材料库/模型树；保留两个拖拽分隔条、
中文步骤、参数范围、材料覆盖、树折叠/显隐、三维选择/坐标轴、保存、生成与格式导出。
边界入口按用户后续指示移除，属于 TASK16 功能变更。

标题栏高 52 px，面板标题与检查器 tab 使用统一灰色条带。输入框保持白底，数值使用等宽
数字，主操作使用克制的蓝色。1280 px 左右减少导航和三维视图的最小宽度以容纳四区；
1100/650 px 断点继续沿用既有分区堆叠方式。三维材料颜色、相机和交互保持，背景改为中性灰。

验收使用真实后端与浏览器，核对参数页、材料库和模型树，保存工作区截图；前端测试和
构建通过。没有为纯外观添加重复实现的样式断言。
