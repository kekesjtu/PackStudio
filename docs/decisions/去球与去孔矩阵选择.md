# 去球与去孔矩阵选择

## 决策

显式去球单元（`bga.omitted_cells`）与去孔单元（`bga.via_configuration.omitted_cells`）以主阵列行列数构成的矩阵呈现，交互对齐 Word 表格的单元格选择：单击切换单个格子，按住左键拖动即框选一块矩形区域。

- 矩阵行列顺序与主阵列一致，行号、列号从 1 开始标注，对应数据中的 `row`、`column` 从 0 开始。
- 单击可分散点选单个格子，多次操作与已有单元合并，不会覆盖其它已去除格子。
- 拖动起点决定本次框选的方向：起点是已去除格子时框选为恢复，起点是保留格子时框选为去除；一次拖动结束时统一写回数据并标记方案已修改。
- 矩阵上方提供「重置为空」按钮，一次清空全部去球单元；没有去球单元时按钮禁用。
- 已去除格子填充深灰，拖动中的框选范围以浅色预览区分去除与恢复。
- 矩阵宽度随列数变化，超出栏目宽度时横向滚动，高度上限 240px 时纵向滚动。
- 矩阵尺寸跟随阵列行列数就地重建，填写或修改行列数后立即更新，不需要切换步骤。

## 展开层级

去球、去孔矩阵都挂在「显式去球」「显式去孔」勾选框下，未勾选时不占用界面；勾选状态只是界面展开开关，不写入方案数据。方案里已有去球或去孔单元时，进入对应步骤默认展开，避免已配置的位置被藏起来。

热通孔步骤按启用层级逐步展开：

1. 只显示「包含热通孔」勾选框。
2. 勾选后显示通孔长度、直径、镀层厚度、间距、行列数量，以及默认未勾选的「启用通孔去除」。
3. 勾选「启用通孔去除」后才显示中央去除行数与列数、默认未勾选的「显式去孔」；再勾选「显式去孔」才展开去孔矩阵。取消任一层勾选只收起控件，已填数据保留在方案中。

「启用通孔去除」首次勾选时把缺失的中央去除行数、列数补为 0，避免未填写就生成时报错。

## 理由

逐个填写行列坐标既无法直观看出阵列形状，也容易填出越界坐标；矩阵与主阵列同构，框选与表格选择习惯一致，能直接看出哪些位置缺球。逐格去球与去孔在多数封装里并不使用，分层展开让默认可用的界面只剩少量勾选框，减少无关参数干扰。
