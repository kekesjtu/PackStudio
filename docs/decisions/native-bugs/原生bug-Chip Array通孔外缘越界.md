# Chip Array 4 × 4 mm 预设的通孔外缘越界

`ChipArray_24_4X4mm_0_8` 的原生 X、Y 通孔偏移均为 0.4 mm。五行五列的焊球阵列节距为 0.8 mm，最外侧球心坐标为 ±1.6 mm。沿正向偏移后，最右列和最上行的孔中心落在基板边界 2.0 mm 处。

在 PackStudio 的详细通孔模型中，直径 0.2 mm 的通孔用等面积方块表示，半边长约为 0.0886 mm。按原生偏移建模，通孔外缘超出右侧和上侧边界各约 0.0886 mm。

PackStudio 对此预设采用 0.3 mm 的 X、Y 偏移。最外侧孔中心坐标为 1.9 mm，孔外缘距板边约 0.0114 mm。
