# Wirebond PBGA 阻焊层不覆盖承载台

阻焊层只保留在键合线开口以外的基板表面，不覆盖承载台。设 $A_1$ 为基板底面高度，$A_2$ 为基板厚度，$t_{\rm da}$ 为粘接层厚度：

$$
z_{\rm mask}=A_1+A_2
$$

承载台顶面为基板顶面，粘接层直接落在承载台上，芯片底面高度为 $A_1+A_2+t_{\rm da}$，塑封厚度至少覆盖粘接层与芯片。

PACK 原生在承载台上再叠一层阻焊层，粘接层与芯片整体抬高一个阻焊层厚度，承载台到芯片的热通路被阻焊层隔断。原生对照样本见 [默认模型](../../../flotherm_pack_data/packages/pbga_wb/baselines/default/model.xml)。
