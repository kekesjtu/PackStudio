# SOP 芯片与胶层堆叠

SOP 按承载台、芯片胶、芯片的顺序连续堆叠。胶层底面贴合承载台实际顶面，芯片底面贴合胶层顶面。PACK 原生模型的芯片与胶层从同一底面开始，增大胶厚时不会保持这一接触关系。

键合线高度取芯片顶面与引线顶面的实际高差。设 $t_d$、$t_{da}$、$t_f$、$t_l$ 分别为芯片、胶层、承载台与引线厚度，$d_f$ 为承载台底面相对引线底面的下沉量：

$$
H=z_{\rm die,top}-z_{\rm lead,top}
=t_d+t_{da}+t_f-t_l-d_f
$$

键合线各段的高度与折弯方向共用该端点高差。塑封体容纳校验采用堆叠后的实际芯片顶面。
