# FC PBGA 通孔等效基体导热率

FC PBGA 的 Core Vias 使用 Orthotropic Cuboid 时，基体取所选基板材料。各向同性标量导热率按三个方向的同值分量参与等效。PACK 的各向同性基板分支会将基体导热率按零处理，PackStudio 使用材料的实际导热率。

设 $\phi$ 为包络内保留通孔的体积分数，$k_v$ 为按镀层比例计算的单孔轴向导热率，$k_{b,x}$、$k_{b,y}$、$k_{b,z}$ 为基体各向导热率：

$$
k_x=k_{b,x},\qquad k_y=k_{b,y},\qquad
k_z=\phi k_v+(1-\phi)k_{b,z}
$$

显式去孔后按实际保留孔数计算 $\phi$。等效密度按体积加权，比热按质量加权，基体密度与比热均来自所选基板材料。
