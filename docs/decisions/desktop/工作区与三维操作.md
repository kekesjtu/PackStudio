# 工作区与三维操作

向导、三维区及模型树与属性区支持拖动分隔条实时调整尺寸，区域内部同样支持上下分隔。

中央工作区提供同级的“三维模型”和“示意图”标签页。切换栏目时保留当前标签页，示意图随栏目更新。“建模与局部网格”栏目对应空白示意图页。

三维模型与示意图共用同一套组件配色映射，配色在功能区“配色”组中切换。默认统一配色：三维模型与示意图使用同一套配色方案。勾选“按材料着色”后，三维模型改用材料库中该块材料的颜色，示意图仍按当前配色方案绘制。选中块显示高亮，塑封保持半透明。

配色方案提供经典、柔和、莫兰迪、暖阳、蓝调五套，切换只作用于当前会话，不写入方案文件。

各套配色通过色相和明度共同区分相邻组件。莫兰迪保持灰调，暖阳以暖色为主并辅以冷色，蓝调以冷色为主并辅以暖色，避免同图组件集中使用相近颜色。

三维视图左键拖动旋转、右键拖动平移、滚轮缩放。旋转和平移保留选择，单击执行实体选择。右下角使用 XYZ 坐标轴指示方位，左下角状态栏显示操作和模型状态。底部比例尺使用固定屏幕长度，以视图中心深度换算毫米标注，随相机缩放和视区尺寸更新。

PackStudio XML 导出使用文档与向外箭头图标。
