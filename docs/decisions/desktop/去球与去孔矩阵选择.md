# 去球与去孔矩阵选择

显式去球 `bga.omitted_cells` 与显式去孔 `vias.omitted_cells` 使用与对应阵列同尺寸的矩阵。界面行列号从 1 开始，方案索引从 0 开始。修改阵列行列数后就地更新矩阵。

- 参照 Word 表格单元格选择。单击切换一格，按住左键拖动选择矩形区域。起点为已去除格子时恢复区域，为保留格子时去除区域。保留区域外的选择，拖动结束后统一写回并标记方案已修改。
- 已去除格子用深灰显示，拖动预览用浅色区分去除与恢复。矩阵溢出时横向滚动，高度超过 240 px 时纵向滚动。
- 矩阵上方的“重置为空”清除当前去除名单，名单为空时禁用。显式去除开关只控制矩阵展开，已有去除单元时进入栏目默认展开。

热通孔按“包含热通孔 → 启用通孔去除 → 显式去孔”逐级展开。启用通孔后展示该封装适用的几何与阵列参数，QFN 提供通孔长度，基板类封装由层栈确定通孔高度。启用通孔去除后展示中央去除行列数。初始值来自预设，建模取中央去除区域与显式孔位的并集。关闭任一层时收起对应控件并保留已有数据。
