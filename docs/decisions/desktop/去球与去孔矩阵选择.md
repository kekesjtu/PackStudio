# 去球与去孔矩阵选择

显式去球 `bga.omitted_cells` 与显式去孔 `vias.omitted_cells` 使用与对应阵列同尺寸的矩阵。界面行列号从 1 开始，方案索引从 0 开始。修改阵列行列数后就地更新矩阵。

- 参照 Word 表格单元格选择。单击切换一格，按住左键拖动选择矩形区域。起点为已去除格子时恢复区域，为保留格子时去除区域。保留区域外的选择，拖动结束后统一写回并标记方案已修改。
- 已去除格子用深灰显示，拖动预览用浅色区分去除与恢复。矩阵溢出时横向滚动，高度超过 240 px 时纵向滚动。
- 矩阵上方的“重置为空”清除当前去除名单，名单为空时禁用。显式去球的勾选框为保存在方案中的业务启用开关：勾选后显示矩阵并应用、校验名单；取消后隐藏矩阵，名单保留但不参与建模与校验。进入栏目时按保存的开关状态显示，不依据名单是否为空推断启用状态。
- 显式去球不依赖“主阵列中心去球”开关。启用显式去球时，BGA 按需切换为离散建模，字段旁持续提示当前约束。

FC PBGA 的 Core Vias 和 Wirebond PBGA 的 Thermal Vias 使用孔位矩阵直接选择去除位置，空名单表示保留完整阵列。矩阵随通孔启用而显示，不设置独立去孔开关或中央去除行列数；关闭通孔时名单保留，不参与生成与校验。原生孔位表通过 DES 的 `.var3` 附件保存，列表记录保留孔位；内部 `vias.omitted_cells` 记录去除孔位，转换时取阵列补集，并转换行方向。

QFN 不支持去孔，通孔按完整矩形阵列生成。Chip Array 不提供独立去孔，通孔位置跟随焊球阵列；FC PBGA 增层微通孔按总孔数等效。示意图中 QFN 绘制完整阵列，PBGA 仅按实际孔位名单显示去孔，不固定绘制中央空区。
