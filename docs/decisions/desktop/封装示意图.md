# 封装示意图

示意图参照 PACK 左二栏，使用等比缩放的矢量剖面、俯视图和尺寸箭头，解释封装结构与参数的几何含义。字段名称与示意图标注一致，数值符号单独显示。层表采用“层深 zn (mm)”与“层厚 tzn (mm)”列名。

画面保留组件、名称引出、尺寸、图例与必要的坐标轴。焊球、通孔、Slug 与封装总图等需要方位的视图才绘制坐标轴。使用高饱和度配色区分组件，尺寸线和箭头为黑色，图例按每行实际宽度居中。凸点与 BGA 焊球使用同一蓝紫色系，均画为正圆，同图时凸点尺寸更小。Slug 顶部与塑封顶面齐平。

同一封装、同一构图的栏目共用固定位置与比例的基础图形。各图标注所属栏目的尺寸，使用固定的组件示例。顶部结构类型、顶盖加强环和焊球交错改变构图，其余启用开关由参数编辑区反映。凸点图始终画满阵列，倒装凸点剖面始终展示底填充。总数用箭头指向相应组件或阵列，文字与引线留出间距。

- 通孔、金属层和增层的局部图用圈选和引线标出剖面中的来源。Chip Array 通孔偏移以对应焊球中心为基准，X 正向向右，Y 正向向上。
- 中央焊球使用完整主阵列加独立中央阵列，标注列数 MDc 和行数 MEc。焊球去除以虚线框标示空白区域，剖面和俯视均省略该区域的球形，标注相对两侧满布区域的列数 MDp 与行数 MEp。
- Slug 结构图展示顶部圆台、台阶、裙边、支脚、支脚粘接层及相关尺寸。
