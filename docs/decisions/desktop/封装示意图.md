# 封装示意图

示意图参照 PACK 左二栏，使用等比缩放的矢量剖面、俯视图和尺寸箭头，直接呈现当前封装配置。字段名称与示意图标注一致，数值符号单独显示。层表采用“层深 zn (mm)”与“层厚 tzn (mm)”列名。

画面保留组件、名称引出、尺寸、图例与必要的坐标轴。焊球、通孔、Slug 与封装总图等需要方位的视图才绘制坐标轴。使用高饱和度配色区分组件，尺寸线和箭头为黑色，图例按每行实际宽度居中。凸点画为正圆，与 BGA 焊球同图时尺寸更小。Slug 顶部与塑封顶面齐平。

同一封装、同一构图的栏目共用固定位置与比例的基础图形，切换栏目时更新标注。示意图随参数配置更新，模型生成前即可查看。

- Chip Array 的金属层和热通孔分别有细节图。通孔偏移以对应焊球中心为基准，X 正向向右，Y 正向向上。
- 中央焊球使用完整主阵列加独立中央阵列，标注列数 MDc 和行数 MEc。焊球去除以虚线框标示空白区域，剖面和俯视均省略该区域的球形，标注相对两侧满布区域的列数 MDp 与行数 MEp。
- Slug 结构图展示顶部圆台、台阶、裙边、支脚及粘接层，标注各尺寸和支脚间隙。Slug 关闭时仍可查看此图。
