# 新建封装与向导导航

参照 Flotherm PACK 的 Create New Package 窗口和左侧向导。

## 新建封装

先按封装类别选择起始模板，再设置设计名称、JEDEC Footprint、子类型及适用的创建选项。Footprint 与子类型来自预设，Bare Die 隐去 Footprint，子类型下拉框仅用于 PQFP 与 SOP。外形与芯片类型按[封装范围](../projects/封装与传热范围.md)固定。

点选即时更新选中状态，下一步异步准备所选模板的数据。返回后保留同一模板的草稿，完成时采用最终选择。加载可取消，取消或关闭后保留当前方案。

## 左侧向导

从上到下为封装示意与标题、常显栏目列表、当前栏目参数区。点击栏目切换并高亮，参数区顶部显示栏目名。概要在首项，由桌面统一展示可编辑的设计名称与只读的封装类型。组件按封装结构排列，BGA 焊球、中央焊球、焊球去除分别成栏，建模选项在末项。

栏目区与参数区可调整高度。常规字段采用左标签、右输入的紧凑布局，单行区域最小高度为 26 DIP，字段间距为 7 DIP；层表占用整行，长内容在参数区内滚动。

复选框统一使用直角正方形外观。参数布尔字段采用整行“勾选框与右侧文字”，创建选项可采用左标签、编辑列勾选框，表格单元格内勾选框无标签并居中。显式去球、去孔的展开头部与普通勾选行保持一致，头部与展开内容间距为 6 DIP，收起或隐藏后不保留对应内容的空白。

FC CBGA/PBGA 顶部切离塑封体时，Slug 自动取消勾选并置灰。切回塑封体后可手动勾选，已填参数保留。
