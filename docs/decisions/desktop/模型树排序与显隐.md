# 模型树排序与显隐

模型树保留父子分组。各级的分组与实体块按 Z 中心从高到低混合排序，分组中心取后代块的 Z 包围区间中心。同高时保留原始顺序，空组置于同级末尾。

模型树与材料库共用行高、20 px 层级缩进、选中与悬停样式。名称与计数分开对齐，分组显示可见块数与总块数。分组用叠层图标，实体用单块立方体，材料用颜色样本。

根节点始终展开。工具栏“全部折叠”收起根节点下各层分组，保留一级分组标题。“全部展开”打开所有分组。

## 选择与检查

点击根节点查看封装类型、组件分组、块数、材料种类、包围尺寸及总功率。点击分组查看该组的块数、材料、包围尺寸和功率。根节点和分组检查清除实体选择，点击实体则显示物性。

普通单击替换实体选择，再次点击唯一选中块时取消。Ctrl 逐项添加或取消，Shift 按当前树中可见实体的显示顺序选择连续范围，Ctrl + Shift 将范围加入已有选择。折叠分组保留组内已选实体。

三维视图同步高亮选中块，单击实体选择单块，单击空白或生成新模型时清空选择。

## 显示与隐藏

右键可显示、隐藏或独显目标。目标为当前块、右键命中的已选块集合，或分组的全部后代。分组部分可见时可隐藏，全隐时可显示。节点与空白区均提供显示全部和隐藏全部。显隐独立于折叠状态。
