# 原生bug：FC PBGA 通孔等效基体导热率

## 决策

PackStudio 将 FC PBGA Core Vias 等效分支对各向同性基板的导热率清零行为认定为 PACK 原生 bug。
Core Vias 等效计算统一使用基板材料的三向导热率，各向同性材料按同值三向张量参与计算。

## 建模规则

适用模板为 `pbga_fc`，适用组件为 Core Vias 的 Orthotropic Cuboid 等效块。
标量导热率 $k_b$ 对应 $k_{b,x}=k_{b,y}=k_{b,z}=k_b$。
导热率数值相等的张量与同值标量采用相同计算规则。

设 $\phi$ 为包络内实际保留通孔的体积分数，$k_v$ 为按镀层比例计算的单孔轴向导热率：

$$
k_x=k_{b,x},\qquad
k_y=k_{b,y},\qquad
k_z=\phi k_v+(1-\phi)k_{b,z}
$$

基体密度、比热来自所选基板材料。密度按体积加权，比热按质量加权。
通孔包络、镀层比例和显式去孔后的填充率分别遵循对应几何及材料规则。

## 依据与范围

依据为用户确认的原生 bug 处理范围，以及
[Vias Equivalent 第 5 节](../../../Flotherm_PACK_Research/packages/common/Vias/Vias_Equivalent.md#5-孔间基体的来源与材料判断)
中各向同性基板的导出实验。
笔记记录该分支的平面导热率为零，反算基体轴向导热率约为零；各向异性材料分支正常参与等效。

本项等效物性以本决策公式作为验收依据，原生 FloXML 样本作为原生行为证据保存。


## 验收标准

- 相同密度和比热下，标量 $k_b=0.3$ 与张量 $(0.3,0.3,0.3)$ 生成相同等效物性。
- 各向异性基板的 $k_x,k_y$ 分别等于基体对应方向导热率，$k_z$ 符合上述公式。
- 去孔后的 $\phi$ 使用实际保留孔数，基体贡献随 $1-\phi$ 参与计算。
- 密度、比热与同一填充率下的体积及质量加权结果一致。
