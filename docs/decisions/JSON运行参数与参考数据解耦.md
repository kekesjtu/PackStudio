# JSON 运行参数与参考数据

## 决策

生产运行从根目录 `runtime_data/` 读取模板字段、预设、选材与材料物性。
运行库随源码和桌面分发包发布，应用通过自身运行库完成模型生成。
缺失或无效的运行数据通过校验错误返回。

原生记录、来源路径、哈希与运行绑定分别维护。
运行绑定表描述可编辑的字段和材料组件，几何与联动规则由生成代码及回归测试验证。

## 依据

版本化运行库提供来源追溯与独立部署能力。
原始参考导出服务于本机研究，生产运行使用随应用分发的数据。
