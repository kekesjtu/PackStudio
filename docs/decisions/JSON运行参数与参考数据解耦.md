# JSON 运行参数与参考数据解耦

整理日期：2026-10-26。状态：已采用。

## 决策

生产运行从根目录 `runtime_data/` 读取模板字段、预设、默认选材和材料物性。
运行库随源码、wheel 和桌面分发包发布，不读取本地研究目录或调用 PACK DLL。
缺失或无效的运行数据显式报错，不以代码中的重复默认值补齐。

原生记录、来源路径、哈希与已适配字段分开保存，完整转录不等于完整功能实现。
已实现的几何和联动规则由代码及回归测试验证。

## 理由

保留来源可追溯性，同时让应用独立部署，避免生产逻辑依赖个人电脑上的研究资料。

## 维护入口

- 数据结构与提取、验证命令见[参数库说明](../../runtime_data/README.md)。
- 原始参考导出保留在本地 `flotherm_pack_data/`；原生功能研究由外部文件夹维护。
- 测试使用的验证数据保留在 `docs/validation/`。

本记录归并旧参数持久化、源预设适配及运行时解耦说明，不新增 PACK 功能取舍。
