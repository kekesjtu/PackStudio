# PackStudio XML 输出

## 决策

项目使用自定义 PackStudio XML，扩展名为 `.packstudio.xml`，供下游网格与求解模块读取。
格式只表达与笛卡尔坐标轴对齐的三维长方体块、材料和热源，不遵循原生 FloXML。

- `materials` 直接包含当前模型已计算的材料物性，包括等效材料与用户覆盖值；不依赖外部材料库。
- 材料使用文件内局部编号供 `group/material` 引用，不输出运行材料库 ID、来源信息或组分计算配方。
- 每个 `group` 包含使用同一材料的块。一个内部模型组包含多种材料时，按材料拆分导出组，保持每个块的实际物性。
- `block` 使用全局坐标 `x/y/z` 表达左下角（各轴最小坐标），以 `dx/dy/dz` 表达尺寸，无组坐标变换或 `position` 字段。
- `sources` 通过块 ID 关联体热源，功率为 W；同一块的多项功率相加，切分芯片按生成模型分配功率。
- 坐标和尺寸使用 m；密度、比热、导热率使用 SI 单位。保留材料导热类型及温度依赖物性，参考温度使用 K。
- 所有导出数值最多保留 12 位有效数字，以科学计数法保留小量级数值，不使用固定小数位截断；内部计算精度不变。

输出不包含辐射字段（包括空标签）、网格字段、`collapse`、`region`、监视点、原生组件包装、边界条件或追溯 notes。
内部网格字段及方案中的网格参数保留，不写入输出文件。模型只维护固体块和热源，不生成非物理区域或监视点。

## 契约与参考

- [PackStudio XML 契约](../../output_format/packstudio/README.md)定义字段和引用关系，并提供示例。
- 导出回归检查八类模板的块坐标、材料物性、组引用、功率与输出字段范围。
- 原生 FloXML、厂商 XSD 和原生导出证据仅用于独立研究和物理量比较，不作为产品输出契约或运行依赖。
