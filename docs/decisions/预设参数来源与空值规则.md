# 预设参数来源与空值规则

日期：2026-10-26。状态：采用。

## 参数来源

封装几何、材料与布局参数从所选 preset 的原生记录读取，用户输入覆盖该方案中的对应值。
不设置公共封装默认值文件，也不从其他预设、模板编辑初值或代码常量补齐缺失尺寸。
原始预设及材料库保持只读，方案修改仅用于当前页面的模型生成与导出。

模板负责向导字段、校验规则、选项以及 PackStudio 的建模表达策略。
Bare Die 的项目尺寸预设保留在其模板的预设列表中，不伪装成原生 PACK 数据。

## 空值与分支切换

依据用户确认的 Flotherm PACK 原生行为：原生记录未填写数值，或字段标记为
`not_applicable` 且没有数值时，界面保持空白，数据用 `null` 表达。
原生确实保留数值的字段仍读取该值，不因分支关闭而将它清空。

未启用的中央焊球、去球、热通孔等分支不要求填写无关参数，也不参与模型生成。
用户启用分支后，缺少模型生成所需的尺寸或行列数时提示填写；清空输入仍保持空白，
不自动填成 0、1 或任何经验初值。预设中的真实 0 与未填写的空值分别处理。

未启用的布尔开关和空的覆盖列表只表示没有该项操作，不提供封装尺寸。
源预设明确不存在的结构不生成实体，其内部计数不回填到界面作为初值。

## 验证

覆盖预设数值读取、空白显示与清空、启用分支后的必填校验、预设切换、
八类模板生成和 FloXML 导出；原始记录中的未启用分支仍完整保留以供追溯。
