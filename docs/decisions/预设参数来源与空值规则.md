# 预设参数来源与空值规则

## 参数来源

七类封装的几何、材料与布局参数从所选 preset 的内部格式预设读取。
预设基于已核实的原生向导初始化及计算结果，保存规范化的内部字段、材料 ID、布局与必要分支。
原生缺省材料的运行默认值按[材料组与默认材料](材料组与默认材料.md)配置。
Bare Die 使用模板中的基线设置，用户输入覆盖方案中的对应值。
正式预设与版本化材料库按只读数据使用，方案修改用于当前页面的模型生成与导出。
模板负责向导字段、校验规则、选项与 PackStudio 的建模表达策略。
Bare Die 基线包含芯片尺寸、功率、翻转与凸点设置，向导直接提供各参数的编辑入口。

## 空值与分支切换

按用户确认的 Flotherm PACK 原生行为，原生空值和标记为 `not_applicable`
且缺少数值的字段以 `null` 表达，界面显示空白。原生保留的数值按原值读取。

中央焊球、去球、热通孔等分支按开关状态参与模型生成。
启用分支所需的尺寸和行列数通过预设或用户输入提供，缺少必需参数时提示填写。
清空输入后字段保持空白；空值与真实数值 0 分别处理。
布尔开关表达启用状态，覆盖列表表达方案修改，原生结构定义决定生成实体。

Chip Array 与 Wirebond PBGA 在创建时显式选择基板分支；模板声明分支初始化的参数集合，用户覆盖值最后合成。显式输入与默认值相同也属于用户输入，不能据此回填分支值。生成已保存方案时不重新选择或回填分支。
方案的参数与阵列布局统一保存在 Values，布局字段以 `bga.` 为前缀。材料选择单独保存在 MaterialAssignments。基板层栈初始化不改变球位布局，用户输入具有覆盖优先级。
金属层为真实 JSON 数组，研究空槽不生成零厚度行；保留球位转换为内部删除名单时取阵列补集。

## 验证

回归覆盖预设取值、空白显示与清空、分支必填校验、预设切换、八类模板生成与 FloXML 导出。
预设的分支参数与来源标识用于数据追溯，原生协议字段由人工对照表核对。
