# ADR-0013：PTA 固定使用分层矩形布尔建模

## 日期

2026-08-01

## 状态

已采纳；目标 PTA GUI 导入、网格和求解待人工验收。

## 背景

PackStudio 的物理模型由无重叠轴对齐矩形块组成。TASK11 已证明同一逻辑实体的碎片可以在
XY 平面精确恢复为多个加矩形，或一个外包络减去若干空区，从而显著减少 XML 实体。然而
TASK11 在高碎片模型中使用根级 Block Build Mode，这不符合 PTA 封装模型必须按 Layer
组织的约束。

层内 Block 仍具有 `AllRects/Add_sub` 布尔能力。Z 向则只有顶层特例：第 1 个 Layer 在
`IsTopLayer=true` 时允许 Block 厚度与 Layer 厚度不同；普通层不允许。

## 决策

### 1. PTA 只使用 Layer Mode

- 根级 `Structure/Blocks` 始终为空；
- `UseBlockBuildMode=false`；
- 不再按实体收益自动切换模式，也不接受元数据强制根级模式；
- 层从顶层到底层排列，`TopLayerIndex=0`，仅第 1 层设置 `IsTopLayer=true`。

### 2. 顶层利用独立块厚

取所有物理块起始 Z 的最大值作为顶层基面。该平面以上没有新的物理块起点，因此可把所有
穿过该平面的几何裁到共同起点，并按各自终止 Z 保留不同厚度。顶层 Layer 厚度取该基面到
模型最高点的距离，层内 Block 厚度可以小于该值。

### 3. 普通层严格等厚

顶层基面以下继续使用所有物理 Z 边界建立连续区间。跨越区间的物理块逐层切片，每个切片
与所属 Layer 等厚。导出前显式检查这一不变量，任何非顶层厚度偏差都直接报错。

### 4. 布尔压缩限定在兼容挤出内

压缩兼容键包含：原始逻辑源、材料、结构类型、父组、体热源密度、Z 起点和厚度。兼容组内
构造精确 XY 占用，并选择操作数更少的加法矩形集合或外包络减空区。不同焊球、引脚、材料
或热源不能因相邻而合并。

### 5. 物理块仍是模型真值

`PackageModel.blocks` 不改为通用 CSG。前端预览、模型树、边界引用、重叠检查和参考 FloXML
保真测试继续使用显式物理块。层内布尔块是由物理真值确定性派生的 PTA 序列化表达。

## 理由

该方案同时满足 PTA 必须分层和减少细碎块两项要求。顶层特例只用于格式明确允许的范围；
普通层通过等厚切片维持可靠的 Z 语义。二维布尔运算继续压缩 QFN 塑封、引线框周边等高
碎片区域，而不牺牲材料边界和体积精度。

## 结果

- 八类模板统一为同一条 Layer 导出路径，消除了未完成 GUI 验收的根级分支。
- QFN 默认模型保留 7 个 Layer，XML Block 从旧逐碎片 Layer 路径的 3747 个降为 328 个。
- Wirebond PBGA、QFP 和 SOIC 默认模型分别导出 63、124 和 58 个层内 Block。
- 非顶层块厚等于层厚成为自动化不变量，五类高碎片模板逐材料体积保持一致。
- 目标 PTA GUI 的导入、网格和稳态求解仍是交付前人工验收项。
