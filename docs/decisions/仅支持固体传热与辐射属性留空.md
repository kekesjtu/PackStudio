# 固体传热范围与辐射属性留空

## 决策

PackStudio 的功能范围明确为固体传热仿真建模，维护固体几何、导热材料与热源。
辐射及其表面属性不在项目范围内，所有封装模板统一遵循此约束。

代码不读取、存储、校验、计算或传递 `radiation`、`emissivity`、`surface` 等表面辐射相关参数，
界面与运行配置不提供相应参数入口。此处的 `surface` 指表面辐射属性，不影响固体几何面的表达。

## FloXML 输出

导出的 FloXML 在 `attributes` 中固定保留以下空标签：

```xml
<surfaces/>
<radiations/>
```

不生成表面或辐射属性定义、发射率数值，也不在几何对象上绑定表面或辐射属性引用。
原生参考数据中的相关数值不进入运行参数或导出结果。

## 依据

项目定位为固体传热仿真；FloXML 的空标签表达参照
[Bare Die 基线原生导出](../../flotherm_pack_data/template/bare_die/baseline/model.xml)。
