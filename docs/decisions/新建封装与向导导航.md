# 新建封装与向导导航

## 参照与流程

参照 Flotherm PACK 的 Create New Package 窗口与左侧向导布局。原生截图位于
`flotherm_pack_data/template/<模板>/screenshots/`。

新建封装分为“选择起始模板”和“自定义模板”两步。模板按封装类别分组展示；
设计名称、JEDEC Footprint、封装子类型及适用的初始化选项在创建窗口设置。
JEDEC Footprint 列表来自模板预设，封装子类型来自预设的 `package.type`。
Bare Die 没有预设尺寸，不显示 Footprint 下拉框；仅 PQFP 与 SOP 存在多个子类型，其他模板不显示子类型下拉框。
封装外形与芯片类型固定为 Standard Outline 与 Actual Die，见 [封装外形与芯片类型范围](封装外形与芯片类型范围.md)；创建窗口不提供这两项。
创建窗口中的输入属于独立草稿，完成后应用；取消或关闭保留当前方案。
起始模板点选即时更新选中状态，进入下一步时异步准备所选模板的预设与参数。
返回后沿用同一模板的草稿；选择其他模板后按最终选择初始化。加载期间可取消创建。

## 左侧布局

从上到下排列封装示意与标题、常显栏目列表、当前栏目参数区；参数区顶部标注当前栏目名称。
栏目直接点击切换，采用高亮表示当前项。概要在首项，组件按封装结构组织，建模选项在末项。
概要固定展示可编辑的设计名称与只读的封装类型，其内容由桌面界面统一定义。
栏目导航不使用下拉框。BGA 焊球、中央焊球、焊球去除分别作为栏目。

参数区与栏目区可调整高度。常规字段采用左侧标签、右侧输入的紧凑行布局；
层表占据完整宽度，较长内容在参数区内滚动。材料选择先按材料组过滤，再在下拉框中选材；参数枚举保留适合其用途的下拉框。

## 示意图与三维模型

中央工作区提供同级的“三维模型”和“示意图”标签页，用户可自由切换。
切换左上栏目时保留当前视图标签页，示意图内容随栏目更新，相关栏目可以共用同一结构图。
“建模与局部网格”栏目不提供示意图；选择该栏目仍保留当前标签页，示意图页留空。
示意图参考 PACK 左二栏，以按面板可用区域等比缩放的矢量剖面、俯视图、尺寸箭头与参数符号说明结构关系。
尺寸符号与参数区一致，示意图不依赖模型生成。图形只保留组件、组件名称引出、尺寸标注、图例与坐标轴方向，不展示操作说明、页头、页脚、编号、比例声明或剖面与俯视标题。
坐标轴方向只在焊球、通孔、Slug 与封装全图等需要指示方位的图形中绘制。
编辑区的字段显示名称采用对应示意图的标注名称，数值字段的符号单独显示；层表采用“层深 zn (mm)”和“层厚 tzn (mm)”列名。
字段名称与字段符号由 `runtime_data/definitions/` 中的 `label`、`des_symbol` 定义，编辑区直接读取模板。
图形采用高饱和度配色，尺寸界线和箭头使用黑色；凸点采用正圆，散热块顶部与塑封顶面齐平。
凸点与 BGA 焊球同图时，凸点小于焊球；同图的不同部件采用易于区分的颜色。颜色图例按每行实际宽度居中排列。
同一封装、同一构图的栏目共用固定位置与比例的基础图形；切换栏目仅改变标注，组件外形与集合由封装配置决定。
Chip Array 的金属层与热通孔分别提供细节图。热通孔偏移以对应焊球中心为基准，X 正向向右、Y 正向向上。
中央焊球的作用以完整主阵列加中央独立阵列示意。焊球去除以虚线框内的空白区域示意，剖面与平面图均不绘制去除区域的焊球或单球残影。
中央焊球图标注列数 MDc 与行数 MEc，不显示固定数量字样；去球图标注外围满布列数 MDp 与行数 MEp，覆盖相对两侧的满布区域。
Slug 栏目提供独立结构参考图，展示顶部圆台、台阶、裙边、支脚及支脚下粘接层，并标注尺寸及支脚间隙；未启用 Slug 时也能查看该结构参考。

FC CBGA 和 FC PBGA 的顶部从塑封体切换为其他结构时，Slug 复选框自动取消勾选并置灰。切回塑封体后可手动勾选，已填写的 Slug 参数保留。
