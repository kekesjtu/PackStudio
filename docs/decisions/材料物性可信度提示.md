# 材料物性可信度提示

## 判定规则

原生材料记录中的密度与比热可能使用数值 1 作为占位值。
密度恰好等于 `1 kg/m³`，或比热恰好等于 `1 J/(kg·K)` 时，界面显示“物性待核实”。
判定直接使用原生数值及当前方案的覆盖值。

## 界面行为

材料库列表、组件选材的当前值与下拉选项在材料名称旁显示紧凑标签。
修改当前方案的物性后，标签按相同判定规则即时更新。
模型生成和 FloXML 导出按各自校验流程执行，校验错误通过界面返回。

## 数据与操作

版本化材料库保存来源数值。用户在材料面板中的修改覆盖当前页面的方案，
用于模型生成与 FloXML 导出。
