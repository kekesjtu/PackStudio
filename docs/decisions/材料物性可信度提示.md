# 材料物性可信度提示

日期：2026-10-26。状态：已采用，记录现有功能。

## 背景

原生材料记录中的密度、比热可能使用数值 1 作为占位值。项目保留来源数值，
同时在选材和浏览材料时提示用户核实，避免将占位数据直接当作可靠物性。

## 判定规则

- 密度恰好等于 `1 kg/m³`，或比热恰好等于 `1 J/(kg·K)`，即触发提示。
- 两项只要有一项满足条件就保留提示；当前方案覆盖后按新值重新判定。
- 不使用近似阈值，不根据材料名称或导热率推断可信度。

这是识别疑似占位值的提示规则，不是物性认证。没有提示也不代表材料已经核验。

## 界面行为

材料库列表、组件选材的当前值和下拉选项在材料名称旁显示紧凑的“物性待核实”标签。
物性编辑区域不展开长警告，生成和导出区域不显示集中材料风险提示。
修正当前方案中触发条件的属性后，标签随之消失；仍有一项为 1 时继续显示。

## 数据与操作

保留材料库原值，不自动补值、不写回版本化材料库。用户在材料面板中的修改只覆盖
当前页面中的方案，并用于本次模型生成与 FloXML 导出。
提示不阻止生成模型或 FloXML 导出，也不增加确认步骤；实际校验和导出错误照常显示。
