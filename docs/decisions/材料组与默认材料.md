# 材料组与默认材料

## 决策

组件选材采用“材料组 + 组内材料”两个联动选择框。
材料组采用材料库分类，材料选择框显示当前组中适用于该组件的候选材料。
切换材料组时，同时选择该组中的有效材料；所选材料进入当前方案的建模与导出。

每个组件均提供非空的默认材料组和默认材料，包含条件分支中的组件。
PACK 原生记录中有默认材料的组件沿用原值；原生材料缺省或为 No Attachment 的组件，
使用运行模板中明确配置的合理默认材料。默认材料组由默认材料的分类确定。

## 缺省材料配置

| 组件 | 默认材料组 | 默认材料 |
| --- | --- | --- |
| FC CBGA/PBGA 散热块 | Metals | Copper (Pure) |
| FC CBGA/PBGA 散热块支脚粘接层 | Attachment Materials | Stiffener Adhesive (Typical) |
| FC PBGA 上部、下部增层介质 | Substrate Dielectrics | BT |
| Wirebond PBGA 散热块 | Metals | Copper (Pure) |
| Wirebond PBGA 散热块支脚粘接层 | Attachment Materials | Stiffener Adhesive (Typical) |
| PQFP、SOP、QFN 板侧散热焊盘 | Metals | Copper (Pure) |
| PQFP、SOP 散热焊盘焊料 | Alloys (Solders) | Solder (Sn63/Pb37) |

铜用于散热块的导热，粘接层使用专用胶材料，BT 用于有机基板增层介质。
Bare Die 的凸点焊料及底填充材料使用模板中的基线设置。

## 数据与验证

原始参考记录保留 PACK 的材料值与空值，用于来源追溯和原生行为对照。
运行模板保存 PackStudio 的缺省材料配置，材料库分类用于材料组联动。
此约定适用于默认选材；几何尺寸和阵列参数遵循[预设参数来源与空值规则](预设参数来源与空值规则.md)。

回归检查组件默认材料及其分类、组内筛选、切换材料组、预设切换和生成/导出的材料绑定。
