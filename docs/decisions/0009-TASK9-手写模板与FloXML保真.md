# ADR-0009：手写生产模板以 FloXML 为开发期真值

## 日期

2026-07-30

## 状态

已采纳。本 ADR 补充 ADR-0007，并纠正对“手写模板”的错误理解。

## 背景

ADR-0007 决定生产运行不读取参考目录，这一边界是正确的。但解耦后的部分模板使用了通用
几何或经验公式，导致部署虽然独立，模型却偏离已经验证的基准 FloXML 和单变量差异。用户
明确要求：`flotherm_pack_data` 是开发期参考，不是运行时数据库；模板仍应由工程师把参考
事实逐项写入生产代码，而不是重新设计封装结构。

## 决策

### 1. 区分运行时依赖与开发期真值

- `src/packstudio` 不读取、解析或定位参考目录。
- 默认坐标、尺寸、拓扑、材料和参数联动以已验证 FloXML/差异为开发期真值。
- 参考事实必须转录为显式字段、公式、常量和测试，随生产代码版本发布。

### 2. 同时保留原始保真与求解输入合法性

- 开发期保真测试直接比较生成器归一化前的 cuboid，允许 FloXML 中的嵌入和重叠。
- 最终 `PackageModel` 继续执行 ADR-0005 的确定性矩形差集，保证无正体积重叠。
- 因而“参考原始拓扑”和“下游合法矩形分区”分别验证，不互相替代。

### 3. 明确允许的差异

- Flip-chip bumps + underfill 按用户要求固定为有厚度正交各向异性等效层；材料表达可与
  FloTHERM PACK 基准 bump cuboid 不同，几何包络和 Z 堆叠仍须一致。
- BGA 专用中央焊球、去球、静态空气与分区规则沿用 TASK5/ADR-0005。
- 除上述约束和输出归一化外，不允许以“更通用”或“更合理”为由改变参考模板结构。

### 4. 开发期双重回归

- 默认回归比较 8 类基准的 cuboid 几何与材料属性。
- 单变量回归从参考 manifest 读取测试用模型，与手写字段公式逐块比较。
- 另有运行时独立性测试拦截文件读取，证明生产请求不依赖上述测试资料。

## 理由

只做运行时独立性测试能证明“没有读文件”，不能证明“手写正确”；只在运行时解析 FloXML
虽然容易匹配，却破坏部署独立和代码审查边界。开发期以参考数据生成黄金对照、生产期只执行
手写代码，能同时满足保真、可审查和脱离资料运行。

## 结果

- 八类默认 cuboid 数量、原点和尺寸与基准一致。
- 已映射的 320 个数值单变量与 54 个 Flip-chip 顶盖分支/变体形成结构化回归。
- 参考目录可从部署包移除；删除后不会改变生产模板行为。
- 以后新增或修正参考证据时，必须显式修改模板代码和回归，不允许动态改变生产结果。
