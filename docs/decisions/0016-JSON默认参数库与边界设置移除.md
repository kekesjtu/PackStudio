# ADR-0016：JSON 默认参数库与边界设置移除

日期：2026-09-30。状态：已采用。

用户要求将安装目录调研得到的 342 份文本预设持久化，并让程序通过序列化文件设置默认值；
随后要求删除 PackStudio 的边界条件设置功能。

采用根目录 `default_parameters/`，分别保存无损源转录、生产模板与集中材料库。源转录同时
保留 raw_fields 与类型化 values，原始空字段用 null 表示，不猜测单位或选项含义。
运行时从 JSON 构建 dataclass 字段契约与材料对象，移除旧字段构造器、Footprint 常量和基准
材料数值；保留生成器的几何算法与约束。21 个已验证源预设的 Ld/Wd 运行时从家族文件读取。

保留已有 25 个生产选项；342 条源记录全部存储，不将尚未映射验证的记录自动开放为可生成
选项。明确区分资料完整性与适配验证，后续扩充通过数据映射及逐族几何回归进行。

开发模式读取仓库库文件，wheel 通过 setuptools data-files 安装到环境的数据目录，冻结
EXE 读取 PyInstaller 打包的数据目录。缓存读取结果并返回独立副本；修改后重启，缺失或
无效的参数库显式失败，无硬编码回退。

生产请求删除 environment，向导删除边界步骤，生成模型 boundaries 为空，PTA 不再注入
默认/PCB/顶部对流边界。OtherThermalBondary 使用样例已出现的 i:nil=true；下游配置散热。
领域模型和通用导出器保留对外部模型显式边界的表示与输出能力。旧浏览器保存记录恢复时
丢弃 environment，保留几何、选材、材料覆盖、功率、网格、BGA 配置与名称。
