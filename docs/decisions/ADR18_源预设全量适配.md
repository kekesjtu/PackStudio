# ADR18：342 个 PACK 源预设的生产适配

日期：2026-10-01；状态：已采用。

## 背景

完整 `.des` 转录已保存，但只有既有 21 个非 Bare Die 规格接入选择器。
源字段完整度因家族而异，名称球数、区域奇偶、材料名称也不能等同于完整生成模型。

## 决策

用 `default_parameters/source_adapters.json` 声明七类家族的直接字段映射、派生操作、
缺值策略和逐记录修正。运行时读取源 JSON，生成规格关联值，不生成代码中的默认值表。
342 个源全部可选；既有标识与四个 Bare Die 规格保留，总数 346。

保留七个已对照默认基线和其动态 Ld/Wd 映射；新规格逐项读取源参数。
缺失的基板/金属层/通孔信息继承审核模板 JSON，继承字段和源材料名保存于逐记录审计。
继续使用家族审核等效材料张量，用户自选材料优先；不从名称伪造物性。

BGA 优先使用可读取布局。MDp/MEp 解释为全填充行数；去除区取全阵列与该数之差。
Chip Array 的 balls 列表解释为现存 X/Y 坐标，转为显式去球补集；矩形去球行列同时为 0
支持只去除显式单元。源记录奇偶不匹配时显式启用非对称定位，沿负轴取整并提示偏移。
一般用户配置继续默认要求中心对称。源名称球数冲突保留布局并提示，不推测缺球位置。

QFN_3X3_6 的 ME/ey 缺失，MD=3，采用双侧结构；空侧引脚数为 0，空侧键合线也省略。
SOIC 共面端点不创建零高度垂直键合线；原有有效基线和单变量参考几何保持回归一致。

UI 切换规格应用 schema 的 preset_bga，保留用户表达方式及独立分支、功率和选材。
API 的 BGA 字段按显式覆盖优先；省略字段继承源配置，完整对象覆盖全部配置。

## 验证与限制

`tools/validate_source_presets.py` 对全部源建立 510 种模型配置，验证几何引用、无重叠、
正尺寸、两种 BGA 表达球数、ECXML 安装版 XSD 和 PTA XML。报告持久化于参数库，
记录输入 JSON 哈希，测试禁止使用过期报告。

该验收不代表新规格均已与原生 PACK 导出逐块或逐物性核对。46 个名称球数冲突、
两个奇偶不同的区域及缺值继承均有审计。342 条源键值及 .des 来源哈希保持原样。参数 JSON 与文件校验采用 UTF-8/LF，
研究快照哈希在 LF 规范化后计算，避免 Git 检出改变换行导致校验失败。
