# 封装外形与芯片类型范围

日期：2026-10-26。状态：已确认。

## PACK 原生行为

除 Bare Die 外，其余七类封装提供 Standard Outline / Non-Standard Outline。
QFP 和 SOIC 提供 Actual Die / Thermal Die。

## 项目决策

- 只提供 Standard Outline，不实现 Non-Standard Outline 分支。
- 只提供 Actual Die，不实现 Thermal Die 分支。
- 不为上述固定行为展示只有一个值的选项框。
