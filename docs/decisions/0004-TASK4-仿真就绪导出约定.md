# ADR-0004：TASK4 仿真就绪导出约定

## 日期

2026-07-12

## 背景

TASK3 导出的 PTA 文件可以打开，但层级最大网格尺寸为未设置状态，边界也只有用户主动填写
后才存在。模型没有 PCB 几何时，若仅对微小封装表面施加自然对流，1 W 默认热源会得到不适合
首轮工程判断的极高温升。同时，BGA 层曾沿用 underfill 基体，塑封也没有覆盖芯片顶面。

PTA 示例表明 `MeshSizeX/Y/ZExpression` 属于层和块的输入属性，不要求同时携带 `<Mesh>`
网格实体。因此可以在不接管网格生成的前提下，让文件具备可执行的网格控制和热边界初值。

## 决策

### 1. 网格预设只写最大尺寸

- 提供粗、标准、细三档，XY 目标划分数分别为 12、24、40，Z 目标划分数为 1、2、4。
- 每个 PTA 层按该层实际 X/Y 包络与厚度计算三个非零最大尺寸。
- 块级三个尺寸写 0，表示继承层设置。
- `<Mesh>`、节点、单元和任何求解结果仍由 PTA 生成，PackStudio 不导出。

### 2. 使用三层热边界覆盖

- 未明确指定的外表面由 `OtherThermalBondary` 接管，默认 300 K、10 W/(m²·K) 自然对流。
- 焊球接触底面始终具有 PCB 侧显式边界。用户输入 PCB 到环境的总热阻，导出器根据目标总
  面积换算 `h = 1 / (R × A)`，默认 20 K/W。
- 最高结构顶面始终具有显式边界。默认使用外表面对流；用户可启用顶部到环境总热阻覆盖。

20 K/W 是为了在缺少 PCB 几何时提供有限主要散热路径的工程起点，不是 `RθJB`，也不是对任意
PCB 的精度承诺。TI 的封装热指标资料说明 PCB 是常见的主要散热路径，且板设计会显著改变热
指标；COMSOL 的芯片冷却示例采用 10 W/(m²·K) 作为经验对流系数。正式模型必须按实际 PCB、
气流和实测数据校准。

- [TI：Semiconductor and IC Package Thermal Metrics](https://www.ti.com/lit/an/spra953d/spra953d.pdf)
- [COMSOL：Electronic Chip Cooling](https://doc.comsol.com/6.4/doc/com.comsol.help.models.heat.chip_cooling/chip_cooling.html)

### 3. BGA 层固定使用静态空气基体

- BGA 默认改为全阵列。
- BGA 等效材料以焊料和空气混合，离散模式的单元间隙与所有去球区域也必须填空气。
- 等效模式只生成阵列包络内的焊料/空气复合块；离散空气也只填充阵列单元和去球区域，阵列
  包络与基板边缘之间不建模。
- 后端拒绝非 `air` 基体、关闭离散空气块或将去球区域设为不建模的请求。

### 4. 倒装凸块与塑封

- 倒装凸块只允许正交各向异性等效层，前端移除离散选项，后端负责最终约束。
- 塑封保留与凸块层、芯片层共层的两组矩形环，并在芯片顶面增加完整盖层。启用后共 9 块，
  芯片最高面低于塑封最高面。
- 塑封与顶部结构同时启用时，顶部结构从塑封盖层继续向上堆叠并必须覆盖塑封包络。

### 5. 工作区交互

- 焊球去除和中央焊球合并为“焊球样式”。
- 新增“网格尺寸”和“边界条件”属性页。
- 左侧导航固定；属性栏与预览、预览与检查器之间各设置一个分隔条。
- 删除任务标签、重复副标题、输入职责提示和模型树右侧重复结构类型。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 继续让 PTA 自动决定所有网格尺寸 | 用户已确认导入后尺寸未设置，不满足开箱仿真目标 |
| 导出完整 `<Mesh>` 实体 | 越过 PackStudio 与 PTA 的职责边界，且用户明确不需要，未采用 |
| 焊球底面固定 300 K | 相当于理想无限 PCB，通常过度冷却，未采用 |
| 所有表面只用 10 W/(m²·K) 自然对流 | 缺少 PCB 主散热路径，默认 1 W 小封装温升过高，未采用 |
| BGA 空气与焊球块重叠 | 违反轴对齐块无正体积重叠约束，未采用 |

## 结果

- PTA 输入文件具备非零层级网格尺寸、默认外表面边界、PCB 侧边界和顶部边界。
- 自动化测试验证字段、面积换算、无 `<Mesh>` 实体和无求解结果；仍需在目标 PTA 版本中完成
  一次人工网格生成和稳态求解，才能关闭下游兼容性验收。
- PCB 与顶部等效热阻是显式可编辑假设，不应被当作实测器件热指标。
