# 方案文件与模型输出

普通预设是随应用分发的只读预制方案，与用户保存的方案共用 `packstudio.project/v4` JSON 契约和导入入口。预设名称与索引键一致。方案保存家族、名称、实际参数与层表、完整材料选择及自定义物性，包括用户明确编辑的等效物性。

JEDEC Footprint、预设 ID 和来源属于创建或取数环节。导入完整方案直接读取文件中的实际参数与材料选择。字段定义见[运行库说明](../../../runtime_data/README.md#完整方案与四层配置)。

[PackStudio XML](仅保留PackStudioXML输出.md)供下游网格与求解软件读取，方案导入使用上述 JSON。
