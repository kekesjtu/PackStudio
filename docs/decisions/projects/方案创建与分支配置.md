# 方案创建与分支配置

创建弹窗记录草稿，完成时以最终选择初始化一次。Desktop 与 CLI 共用创建语义。预设提供完整参数、材料选择与自定义物性，Bare Die 自动使用唯一的内置预设。

合成顺序为预设 → 创建分支设置 → 用户提交值 → 创建层栈计算。显式输入按是否提交判断，`null`、`0`、`false` 和与默认值相同的输入均保留。用户提交的层表优先，层栈计算保留原焊球布局和材料选择。无法计算的派生值留空，业务校验在生成前执行。

## 四层基板

Chip Array 与 Wirebond PBGA 完成创建且最终选择四层时，按需读取各自的四层配置。先应用共用层表、基板厚度及家族设置，再应用对应预设的散热片尺寸差异，最后应用用户提交值并计算层栈。两层创建以普通预设为起点。

## 露出焊盘

SOP 与 PQFP 完成创建且最终启用露出焊盘时，按需读取各自的露出焊盘配置，应用散热焊盘启用状态与厚度，并按配置从引脚高度复制承载台下沉量，再应用用户提交值。

创建分支配置独立于普通预设索引，仅用于完成创建。切换草稿选项、导入方案和生成模型均使用各自已有的数据。分支契约见[运行库说明](../../../runtime_data/README.md#完整方案与四层配置)。
