# 预设来源与空值

七类有 Footprint 的封装以 Flotherm PACK 安装目录 `flocentral/flopack/<family>/*.des` 为原生预设来源。提取时将各 `.des` 文件交给 PACK 初始化，再读取并规范化初始化结果，收录由 PACK 初始化逻辑补齐的参数。

Bare Die 使用项目内置的单一预设，提供芯片尺寸、功率、翻转与凸点设置及初始选材。组件缺省选材见[材料组与默认材料](../materials/材料组与默认材料.md)。

原生空值和缺少数值的 `not_applicable` 项以 `null` 表示，界面显示空白。原生已有数值按原值保留，预设取值的例外见[FC 顶盖侧壁与芯片重叠](../native-bugs/原生bug-FC顶盖侧壁与芯片重叠.md)。关闭结构分支时保留已填值，清空字段后维持空白。启用结构缺少必要值时，生成前提示填写。空值、零和关闭状态各有独立语义。

金属层以数组保存，有效层各占一行。原生空槽省略，原生保留球位转换为删除名单时取阵列补集。
