# 模型 XML 输出

PackStudio 使用自定义 `.packstudio.xml` 作为下游模型接口，输出轴对齐长方体块、自足的实际材料物性和按块关联的体热源。输出保留导热类型、温度依赖物性与块的重叠关系。一个模型组使用多种材料时，按材料分组。

网格划分、边界条件与求解由下游设置。内部网格参数留在方案和建模核心，辐射属性、非物理区域、监视点与来源记录留在输出范围之外。原生 FloXML 用于研究对照。

PTA 工程使用独立块建模。仅在 PTA 导出阶段裁剪重叠区域，背面散热片优先，一般组件其次，塑封和线焊 BGA 的介质基体最后。同级由体积较小者占用，体积相同时按块 ID 的序数顺序决定。规则重复的同材质实体可组成 PTA 矩形阵列，块内按 XY 截面扣除矩形，仅在有效截面变化时沿 Z 拆块。热源按原块的剩余总体积换算功率密度，各段共用热源；有功率的块被完全覆盖时导出报错。网格线和求解结果由 PTA 写入工程。格式与示例见[模型输出格式](../../../output_format/README.md)。
