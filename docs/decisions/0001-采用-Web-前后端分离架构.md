# ADR-0001：采用 Web 前后端分离架构

整理日期：2026-10-26。状态：已采用。

## 决策

使用 React / TypeScript 组织向导和三维界面，本地 Python / FastAPI 服务负责
参数校验、几何生成、等效物性和 FloXML 输出。两者通过 HTTP / JSON 交换数据。

领域模型和生成器不依赖界面，导出器只消费统一模型。
浏览器模式与独立窗口复用相同的前端产物和后端服务。

## 理由

将交互与建模计算分开维护，并复用现有 Python 计算生态及浏览器三维显示能力。
无需为桌面窗口维护第二套封装建模实现。

## 影响

本地启动和分发需要管理后端生命周期、端口与静态资源。
模块职责见[技术栈](../tech_stack.md)，运行和验证命令见[开发说明](../development.md)。
