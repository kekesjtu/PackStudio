# 重叠块与警告

## 决策

建模引擎、三维渲染与 PackStudio XML 导出允许几何块重叠。
模型检测重叠并返回 warning；界面显示警告，模型生成、预览和导出保持可用。
警告位于三维渲染区右上角，无警告时隐藏；警告面板不阻挡模型操作。
面板可完全收起，收起后只保留一行汇总与问题计数，展开后显示逐条问题并支持点击定位；出现新警告时自动展开。

## 建模规则

封装生成器依据各组件建模决策确定实体的材料、层级和空间范围，并支持重叠实体。
SOP 芯片与胶层的接触关系由[原生bug：SOP 芯片与胶层堆叠](原生bug-SOP芯片与胶层堆叠.md)定义。
重叠检测采用各轴区间的正体积相交；共面接触不视为重叠。
警告包含重叠块对，供用户检查模型；下游软件依据其几何和材料优先级处理重叠。
