# ADR-0031：仅保留 FloXML 输出

日期：2026-10-26。状态：采用。

## 背景与决策

用户明确当前只使用 FloXML。界面、下载 API、导出器、示例、格式契约和维护工具
统一使用 FloXML，移除其他格式的实现、专用测试及说明。

## 契约与验证

- [FloXML 契约](../../output_format/floxml/README.md)维护字段、单位和当前导出限制。
- 厂商 XSD 与示例保存在 `output_format/floxml/`，生产运行不依赖厂商安装目录。
- 保留 `docs/validation/` 的历史验证证据及测试夹具；它们记录原验证时点，
  不作为当前支持格式或已批准功能取舍的清单。
- 现有导出器的实现限制不自动成为相对 PACK 的新增取舍。

该项属于项目输出范围决策，不扩充功能取舍的三项清单。
