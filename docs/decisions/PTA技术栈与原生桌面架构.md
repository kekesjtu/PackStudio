# PTA 技术栈与原生桌面架构

## 目标

PackStudio 前端与后端统一采用本机 PTA 的技术栈，面向 Windows 原生桌面使用。参数向导、材料编辑、模型检查与文件导出无需本地 HTTP 服务。

## 架构约束

- C# / .NET 10；WPF 界面，CommunityToolkit.Mvvm 组织状态与命令。
- HelixToolkit.Wpf 提供矩形块三维预览，Fluent.Ribbon 提供功能区，AvalonDock 提供工作区布局。
- 领域核心通过类型化数据与方法供界面和命令行复用，Newtonsoft.Json 读取运行库与方案，NLog 记录桌面日志。
- 生产应用只依赖 .NET 桌面技术栈；Python 与 uv 用于独立的原生研究和参考数据维护。
- JSON 运行数据与 FloXML XSD 是可分发资源，不依赖本机 PTA、Flotherm PACK 或参考归档。
- 保留八类封装、材料等效规则、均匀芯片热源、模型树和 FloXML 接口契约。
- runtime_data 声明默认值、创建选项、字段/配置结构、可见性、栏目顺序、家族展示元数据、示意图路由、图形样式与模型分组父子关系。通用解释器执行模板初始化声明；Chip Array 与 Wirebond PBGA 的四层创建选项由明确的代码分支按需读取家族四层小契约，配置保存共用设置及具体封装差异。
- Core 负责业务规则、输入校验、层栈计算、几何与材料派生结果；领域模块之间通过强类型模型传递计算结果。模板声明派生值使用的 calculation 与依赖，计算算法由 Core 实现和注册；新增算法需要修改 Core，不在 JSON 中执行表达式。
- UI 展示模板声明与 Core 输出；创建草稿与主向导共用字段编辑器，可观察状态按声明依赖传播变化，显隐使用绑定。控件不创建缺失的领域参数，不重算几何公式。
- 创建草稿、命令行创建与完成创建使用同一初始化管线，显式覆盖记录贯穿编辑与完成阶段。方案格式兼容只在文件读取边界按版本执行，不在模板默认值或工作区加载时补参。
- 材料展示共用 Core 的候选与代表选择规则；同名代表按已分配材料、方案自定义、模型材料、稳定 ID 顺序选取；同一 ID 的物性按方案自定义、模型、材料库的优先级覆盖。模型输出使用完整的强类型几何元数据与显式表面标记。
- 概要内容与普通字段一样由运行数据声明；文档属性保持文档属性身份。仅创建时生效的参数在声明中明确阶段，创建完成后的层表是几何输入，失效初始化参数不参与建模校验。
- CLI 负责研究请求协议适配，Core 不解释研究工具的字段前缀与请求白名单。研究调用使用显式构建产物；构建策略集中在仓库构建入口，诊断对调用者可见。
- 普通预设与可导入方案使用同一完整文件契约，预设 Name 是目录名称。初始化按“模板默认值 → 所选预设 → 显式选择的四层配置 → 用户覆盖值”合成。是否覆盖由输入是否存在决定，禁止通过与默认值相等推断用户意图。已保存方案的参数、层表与完整材料选择直接参与生成，不回填预设；文件不保存预设来源字段。

## 工作区交互

向导、三维模型、模型树与属性三个区域支持拖动分隔条实时调整尺寸；区域内部的上下分隔条采用相同交互。
三维视图左键拖动旋转、右键拖动平移、滚轮缩放；单击保留实体选择，旋转与平移结束保留原选择。
方位指示仅使用右下角 XYZ 坐标轴。左下角状态栏显示操作与模型状态，无固定单位图例。
三维区底部显示固定屏幕长度的比例尺，随相机缩放与视区尺寸变化更新毫米标注，以视图中心深度为参考。
FloXML 导出使用文档与向外箭头图标。

## 技术栈参照

本机 PTA 安装清单声明 .NET 10，CommunityToolkit.Mvvm 8.3.2、HelixToolkit.Wpf 3.1.2、Fluent.Ribbon 9.0.4、Dirkster.AvalonDock 5.0.0、Newtonsoft.Json 13.0.3 与 NLog 4.5.10。使用的第三方运行依赖与参照保持同版本，通过 NuGet 锁文件固定。
