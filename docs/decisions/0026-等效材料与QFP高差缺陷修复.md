# ADR26 — 等效材料与 QFP 高差缺陷修复

日期：2026-10-17；状态：采用。模型版本：2.2。

## 背景

审查和 FloXML 对照确认三项问题：等效引线/连筋被纯金属覆盖；部分物理组分编辑未重算；
QFP 负高差无法生成。ADR22 的实现覆盖不足，需要补齐实际物性计算和最终材料绑定。

## 决策

1. QFP 内/外引线按当前 `B/e` 与塑封/空气重算。X 类在 x/z 混合、Y 类在 y/z 混合；
   SOP 保留原生各向同性混合。密度按体积加权，比热按质量加权。
2. QFP 连筋使用 `G=hypot(a,b)*(1/a+1/b)`，其中
   `a=(D1-Lf)/2, b=(E1-Wf)/2`。面内取对应金属轴值除以 G，法向取塑封值，
   密度/比热保留所选金属，延续审核原生表达。SOP 独立实体连筋继续绑定其金属。
3. bump 与 BGA 在层构造时读取当前物理材料覆盖；WB 顶铜、底铜、flag 从当前组分和
   当前源规格覆盖率重算，与 Via 的铜输入一致。关闭 Via 不阻止铜层重算。
4. 先消费物理组分，再形成衍生材料；用户对衍生材料 ID 的显式覆盖最后应用。
   派生材料保护扩展到对应引线/连筋/铜层组，避免最终选材再次覆盖等效结果。
5. QFP 高差 `delta=td+tda-ddf`，名义长度用 `abs(delta)`；水平段位于两端较高处，
   竖段从低处开始，并随符号在引线端/芯片端切换。零高差不创建零厚度竖段。
   小高差继续保留项目有限厚度竖段选择，不擅自改成 PACK 的省略阈值。

## 验证与限制

保留 PTA/ECXML/FloXML 的各自契约，不改 BGA 去球/静态空气、bump 面内网络，
不修改原生 Via 端部间隙或 Chip Array/SOP die/attach 重叠。
413 案重新生成比较，25 个独立公式/边界测试，分类器新增 2 项回归。
SOP 实体连筋的纯金属是已声明的结构选材，不再混同为 F1 等效引线覆盖缺陷。

PACK 一致性不是物理正确性的充分条件：共用的几何风险、低密度/比热数据、
温度依赖投影、collapsed 与面源/体源差异仍须独立评估。
