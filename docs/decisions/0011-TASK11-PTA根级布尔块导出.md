# ADR-0011：PTA 高碎片结构使用根级矩形布尔块

## 日期

2026-07-31

## 状态

已由 [ADR-0013](0013-TASK13-PTA全分层矩形布尔建模.md) 取代。矩形布尔领域表达和精确
XY 压缩继续有效；根级 Block Mode、自动模式选择及其元数据控制已废止。

## 背景

PTA XML 有两条几何路径：

1. `Layers/Layer/Blocks`：块继承层的 Z 位置和厚度，适合简单连续层叠；
2. 根级 `Structure/Blocks`：块通过自身 `ZOffsetExpression` 和
   `ThicknessExpression` 定位，配合 `UseBlockBuildMode=true`。

两种路径中的 `Block/AllRects` 都不是“一个块只能有一个矩形”。样例显示一个块可以先写多个
`Add_sub=true` 加矩形，再写 `Add_sub=false` 减矩形。旧导出器没有利用这些能力，导致
无重叠归一化后的塑封差集被逐碎片、逐全局 Z 层重复导出。

## 决策

### 1. 保留两种互补几何表达

`PackageModel.blocks` 继续是显式无重叠物理块，负责：

- 三维预览与模型树；
- 材料、热源、边界引用；
- 正体积重叠验证；
- 与手写 FloXML 原始几何的分层验证。

导出阶段另外构造 `RectangularBooleanBlock`，负责 PTA 紧凑表达。不能用布尔实体替换物理块
成为唯一真值，以免前端和边界算法必须实现通用 CSG。

### 2. 只恢复有证据的逻辑整体

规范化器把原始 `DraftBlock.id/name` 写入每个碎片的内部元数据。压缩器只在以下属性全部
相同的碎片之间恢复整体：

- 原始逻辑源；
- 材料；
- 结构类型；
- 父组；
- 体热源密度。

不同引脚、焊球、via 或不同材料即使相邻也不合并。

### 3. 精确正交布尔压缩

每个逻辑源按自身 Z 边界分段。段内使用所有矩形边界建立二维占用网格，再把同状态相邻单元
合并为矩形。导出器比较两种精确表达：

- 已占用区域的多个加矩形；
- 一个外包络加矩形减去全部未占用矩形。

仅选择操作数更少者；两者覆盖完全相同，不进行轮廓近似、间隙吞并或材料均化。

### 4. 自动选择 PTA 构建模式

- 压缩后至少减少 8 个实体：使用根级 Blocks、空 Layers 和
  `UseBlockBuildMode=true`。
- 其余模型：保留既有 Layer Mode。
- `pta_geometry_mode=block|layer` 可用于人工验收和故障回退，默认 `auto`。

Block Mode 中每个块写入独立 Z 偏移、厚度和三向最大网格尺寸。Layer Mode 的顶部到底部
顺序、连续层约束和特殊标志保持原样。

## 理由

单纯合并相邻 cuboid 只能处理完整矩形，无法高效表达“塑封外框减去芯片、键合线和引线”
这类结构；直接丢弃碎片又会改变体积。PTA 原生二维布尔轮廓加独立 Z 挤出正好匹配
PackStudio 的正交几何，能在保持精确体积和材料边界的同时显著减少求解器实体。

## 结果

- QFN 强制 Layer 导出的 XML 实体从 3747 降为 318，减少约 91.5%；导出文本从
  9,839,576 字节降为 965,828 字节。
- QFN 塑封在模型中的 1347 个规范化物理碎片，旧 Layer 路径会展开为 3421 个 XML
  实体，Block Mode 将其表达为 5 个布尔实体。
- Wirebond PBGA、QFP 和 SOIC 的 XML 实体分别从 353、856、477 降为 53、75、30。
- FBGA / FSBGA 从 287 降为 167；其结构较离散，因此收益低于大面积塑封差集。
- 简单 Flip-chip 和 Bare Die 继续走已验证的 Layer Mode。
- 输出格式新增根级 Block Mode 路径，交付前必须执行 PTA GUI 导入、网格和求解验收。
