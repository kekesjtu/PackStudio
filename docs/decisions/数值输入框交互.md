# 数值输入框交互

## 设计约定

所有数值输入框按字段的数据约束分为整数框和小数框。分类依据为字段定义，与当前填写值是否包含小数点无关。

- 整数框右侧始终显示原生上下箭头，步长为 `1`。向导中的 `integer`、`integer_spinbox` 和通用数值控件的 `integer` 参数声明整数类型。
- 小数框步长为 `any`，支持整数值和小数值；单位位于输入框内最右侧。向导中的 `number` 和通用数值控件的默认类型声明小数类型。
- 参数允许范围和补充说明位于输入框下方；未定义下限的字段下限为 0，明确允许负值的字段遵循其定义。
- 数值框获得焦点时选中当前内容，便于直接填写新值。

上下箭头作为整数约束的可见提示，帮助用户区分数量与连续物理量。

## 适用范围

规则覆盖概要页的功率与温度、全部封装向导、BGA 阵列与去球设置、过孔去除设置、材料物性和金属层表格。
金属层表格的深度、厚度和覆盖率均使用小数框。
空值、启用状态与取值范围按各字段的定义处理，禁用整数框保留箭头显示。
