# 数值输入框交互

## 设计约定

所有数值输入框按字段的数据约束分为整数框和小数框。分类依据为字段定义，与当前填写值是否包含小数点无关。

- 整数框右侧始终显示原生上下箭头，步长为 `1`。整数类型统一声明为 `integer`，不以文字重复标注整数。
- 小数框步长为 `any`，支持整数值和小数值；单位位于输入框内最右侧。向导中的 `number` 和通用数值控件的默认类型声明小数类型。
- 字段定义中的允许范围显示在输入框右侧，与输入框同排；补充说明位于下方。上下限同时存在写作 `下限~上限`，仅有下限写作 `≥下限`，仅有上限写作 `≤上限`，`exclusive_minimum` 写作 `>下限`，未定义边界时不显示范围。
- 数值框获得焦点时选中当前内容，便于直接填写新值。

上下箭头作为整数约束的可见提示，帮助用户区分数量与连续物理量。范围提示只呈现定义，不在前端拦截输入，越界值仍由统一输入校验报告。

## 适用范围

规则覆盖全部封装向导、BGA 阵列与去球设置、过孔去除设置、材料物性和金属层表格。
金属层表格的深度、厚度和覆盖率均使用小数框。
表格在添加与删除按钮同排显示定义中的行数范围，列标题附带该列单元格的取值范围。
空值、启用状态与取值范围按各字段的定义处理，禁用整数框保留箭头显示。
