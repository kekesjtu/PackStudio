# 移除无效网格预设

日期：2026-10-26。状态：采用。

## 决策与依据

用户明确删除当前网格预设：粗、标准、细选项没有作用于 FloXML 网格控制，
仅写入模型元数据。PackStudio 当前负责封装模型生成，网格划分交由下游软件。

删除对应界面、前后端请求字段、运行默认值、模型元数据及过时导出提示。
同步维护当前 FloXML 示例；历史验证报告保留原验证时点的数据。

## 兼容与验证

浏览器恢复已保存方案时忽略旧的 `mesh` 字段，保留其他有效参数。
API 不再接受 `mesh` 字段；八类模板的默认请求与 FloXML 输出均不携带网格预设。
验证覆盖已有参数恢复、界面选项移除、API 校验与 FloXML XSD。

本项记录当前无效设置的删除，不定义今后的下游网格接口。
