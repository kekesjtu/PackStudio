# 模型树排序与显隐

## 排序与层级

模型树保留模型的父子分组关系。同级分组与实体块按 Z 中心高度从高到低混合排序。
实体块的高度采用几何中心；分组的高度采用所有后代实体块的 Z 包围区间中心。
相同高度的节点保留模型中的原始顺序，空分组排列在同级末尾。
每层缩进 20px，实体块缩进到所属分组下一层。
模型树与材料库采用一致的行高、缩进、选中与悬停样式，名称与计数分开对齐。
模型分组使用叠层组件图标，实体使用单块立方体；材料条目以颜色样本表示其渲染颜色。

## 交互

左键点击实体块选择模型。一级节点始终展开，标题使用静态文本；二级及更深分组提供折叠和展开按钮。
普通左键点击替换实体块选择，Ctrl 左键逐项添加或取消选择，Shift 左键按当前可见块的显示顺序连续选择；
Ctrl + Shift 左键将连续区间加入当前选择。折叠组内的块参与已有选择，范围计算使用当前可见的实体块。
三维视图同步高亮全部选中块；点击三维实体选择单个块，点击三维空白清空选择，生成模型时清空选择。
分组计数显示可见块数与总块数。工具栏的全部折叠收起所有二级节点，保留一级和二级标题以及更深层的折叠状态；
全部展开打开所有可折叠节点。模型仅包含一级分组时，工具栏折叠按钮显示为禁用。

显隐操作使用右键菜单：

- 实体块：显示或隐藏当前块、只显示当前块。
- 选中实体块：右键菜单作用于全部选中块，提供显示或隐藏所选模型、只显示所选模型。
- 分组：递归显示或隐藏后代块、只显示该分组的全部后代块。
- 节点和空白区域：显示全部模型、隐藏全部模型。

部分可见的分组提供隐藏操作，全部隐藏的分组提供显示操作。
折叠状态与显隐状态独立，分组显隐作用于全部后代实体。
