# ADR-0005：TASK5 组合焊球与尺寸预设

## 日期

2026-07-14

## 背景

TASK4 将中央焊球和焊球去除合并为单一“焊球样式”下拉框，但底层仍使用互斥 `pattern`。
因此用户不能先建立中央去球区，再在空区内加入独立中央焊球。交错阵列也继续暴露在凸点和
焊球选项中，与当前模板只需要规则全阵列的目标不一致。

同时，PCB 侧和顶部边界让用户输入总热阻，再根据当前表面积换算对流系数。用户要求直接
控制 PTA 中实际写入的换热系数。塑封盖层在顶盖或 slug 存在时仍覆盖芯片，也阻断了芯片
与顶部散热结构的直接接触。参考 Flotherm PACK 的建模入口还表明，常用 JEDEC 外形应在进入
细节编辑前一次性预设，而不是逐页修改所有相关尺寸。

## 决策

### 1. 用两个独立功能组合焊球布局

- 删除阵列 `pattern`、交错阵列和互斥的中央模式枚举。
- 默认布局隐式为全阵列；界面只提供“中央焊球”和“焊球去除”两个复选框。
- 焊球去除由对称中央空区和附加显式去球单元组成；空区固定为静态空气。
- 中央焊球由独立的对称行列数定义。两项同时启用时，中央焊球在中央空区内重新加入；中央
  焊球尺寸小于去球区时，中间差值形成空气环。
- 显式单元去除优先于中央焊球，以便用户仍能删除中央区中的指定单元。
- 生成器继续把外围、中央和空气掩码确定性分割为互不重叠矩形块。

### 2. 固定倒装芯片凸点表达并公开派生指标

- UI 统一使用“凸点”，不显示阵列样式；后端输入不再包含样式字段。
- 凸点始终使用规则全阵列和正交各向异性等效层。
- 默认 pitch 为 0.25 mm、直径为 0.12 mm，因此理论单元密度为 16 个/mm²，圆形截面
  填充率为 `π × (0.12 / 2)² / 0.25² ≈ 18.10%`。
- 数量、阵列包络、单元密度和截面填充率在属性页显示，并由前后端测试复核。

### 3. PCB 与顶部边界直接使用换热系数

- 保留 300 K 环境和 10 W/(m²·K) 默认外表面对流。
- PCB 接触底面直接使用 `pcb_convection_coefficient_w_m2k`，默认 1600 W/(m²·K)。该值约
  等于 TASK4 默认 6×6 mm、7×7 焊球模型的 20 K/W 路径所对应的系数，作为无 PCB 几何时
  的工程起点；导出时不再做面积或热阻换算。
- 顶面直接使用 `top_convection_coefficient_w_m2k`，默认 10 W/(m²·K)。
- JSON、领域边界和 PTA `ThirdTypeThermalBoundary` 始终保存同一个用户输入值。

### 4. 塑封盖层取决于顶部散热结构

- 没有顶盖和 slug 时，塑封仍由两层矩形环和一个完整顶部盖层组成，共 9 块并淹没芯片。
- 任一顶部散热结构启用时，只生成两层矩形环，共 8 块；矩形环止于芯片顶面，芯片顶部保持
  开口。
- TIM 从芯片顶面开始，slug 或顶盖按芯片/前一级散热结构校验覆盖范围，不再以塑封外包络
  作为必须覆盖的目标。

### 5. 汇总页提供 10 个基本尺寸预设

- 采用参考图中的 `CBGAFC_49_6X6mm` 至 `CBGAFC_144_10X10mm` 共 10 个名称。
- 每个预设明确封装长宽、BGA 行列和 pitch；球数必须等于行列乘积，阵列必须位于基板内。
- 芯片取封装对应方向的 30%，凸点保持 0.25/0.12 mm 并自动选择可放入芯片的最大规则
  行列；塑封、slug 和顶盖按确定性间隙规则派生。
- 切换预设只覆盖几何与阵列尺寸，不覆盖设计名称、材料、功率、网格和边界。
- 预设切换会恢复默认全阵列焊球样式。界面在切换处提醒用户先保存参数。
- “保存参数”将带版本的完整参数写入浏览器本地存储；下次打开页面时恢复。手工修改任一
  预设几何字段后，汇总页显示“自定义尺寸”。

### 6. 材料库使用可调水平分隔条

材料列表和材料属性之间使用水平分隔条，支持指针拖动、上下方向键和无障碍 `separator`
语义。列表和属性编辑器保持独立滚动，并为下方编辑区保留最小空间。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留一个互斥焊球样式下拉框 | 不能组合去球与中央焊球，未采用 |
| 用第二套独立中央焊球阵列对象 | 可表达不同 pitch，但会显著扩大当前 UI/API；本阶段共享主阵列 pitch |
| 继续输入热阻并在导出时换算 | 用户无法直接控制 PTA 字段，已由直接换热系数替代 |
| 塑封始终覆盖芯片 | 与顶部散热结构接触关系冲突，未采用 |
| 预设切换同时重置材料和边界 | 破坏用户已校准的非几何参数，未采用 |
| 只下载参数文件 | 缺少自动恢复；本阶段选择浏览器本地持久化 |

## 结果

- 默认模型仍为基板、凸点等效层、芯片和 BGA 等效层 4 块，默认请求不再含 `pattern`。
- 中央去球与中央焊球可组合为外围焊球、空气间隔和中央焊球三类区域。
- PTA 显式 PCB/顶部边界与 UI 输入完全一致，不再隐式换算总热阻。
- 塑封与顶部散热结构组合时，芯片顶面具有连续 TIM 接触路径。
- 常见外形可以在汇总页一次应用，参数可保存并在下一次进入时恢复。

本 ADR 局部替代 ADR-0004 中“总热阻边界”“塑封始终淹没芯片”和互斥焊球样式的决策；
网格尺寸、BGA 静态空气和无网格/结果导出约定继续有效。
