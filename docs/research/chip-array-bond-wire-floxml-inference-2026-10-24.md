# Chip Array 键合线等效物性：FloXML 变参反推

日期：2026-10-24。

## 结论与证据边界

仅用 Chip Array 归档 `model.xml`、配套输入 `script.xml` 和已有材料 JSON，
可重建 actualDie / standardOutline 分支两种键合线材料的导热率、密度和比热。
未引用生产生成器、已有材料混合实现、DLL 数值探针或反汇编规则。
本次只新增研究工具、结果和说明，没有修改生产模型。

76 个案例全部通过：基线 1 个、数值变参 60 个、选项/预设变参 15 个。
其中选 4 个案例确定比例系数，其余 72 个案例用于数值交叉验证；不是随机抽样验证。
两种材料各检查 kx、ky、kz、密度、比热，共 760 个数值。
最大相对误差为 `3.848967087616927e-16`，三种独立物性反算的体积分数与公式
最大绝对偏差为 `3.885780586188048e-16`。

逐案例输入、输出、反算结果、预测、误差、来源 SHA-256 见
[验证记录](../validation/chip_array_bond_wire_floxml_inference.json)。

## 反推方法

令 m 为金属、b 为塑封基体。对候选的线性混合关系，分别从输出反算：

```text
f_rho = (rho - rho_b) / (rho_m - rho_b)
f_k   = (k_parallel - k_b) / (k_m - k_b)
f_cv  = (rho*cp - rho_b*cp_b) / (rho_m*cp_m - rho_b*cp_b)
```

三者在浮点舍入误差内相等，支持同一金属体积分数控制密度、并联导热率和体积热容。
基线得到 `f=0.10226538585904275`。

用线径上下界样本的 `f_rho` 做对数比，线径幂指数为 `1.0`；
用 20/30 线样本做同样计算，线数幂指数为 `1.0000000000000007`。
芯片长宽变参则符合 `f` 与 `Ld+Wd` 成反比。

以基线、线径 0.0225、芯片长度 1.08、20 线共四例标定：

```text
C = f_rho*(Ld+Wd)/(N*d)
  = 0.39269908169872414
  = pi/8
```

`Ld/Wd` 从 FloXML 芯片 cuboid 尺寸读取；`d` 从水平键合线 cuboid 厚度读取。
长度统一为 mm。N 的确定见下文；未从材料输出反算 N 后再拿它验证同一输出。

## 最终公式

```text
f = N*pi*d / (8*(Ld+Wd))
rho = f*rho_m + (1-f)*rho_b
k_parallel = f*k_m + (1-f)*k_b
cp = (f*rho_m*cp_m + (1-f)*rho_b*cp_b) / rho

bondwire1: (kx,ky,kz) = (k_parallel,k_b,k_parallel)
bondwire2: (kx,ky,kz) = (k_b,k_parallel,k_parallel)
```

`bondwire1` 绑定左右侧的水平/竖直四块，`bondwire2` 绑定上下侧的水平/竖直四块；
76 例均检查八块及其材料引用。两种材料的 rho、cp 相等。
空球位图案例 f=0，输出退化为基体物性，XML 使用两个方向数值相等的 biaxial 材料表示。

该 f 也有几何解释：芯片周长单位长度的线数为 `N/[2*(Ld+Wd)]`，
单根圆线截面积为 `pi*d²/4`，等效片厚为 d，两者相除即上述公式。
这是对数据拟合结果的物理解释，不是额外的原生实现证据。

## 排除的候选公式

以基线为例：

- 比热直接体积加权得到 `805.300960605718`，原始输出为 `471.674051092418`，
  误差约 `333.626910 J/(kg·K)`；质量加权公式吻合。
- 增强方向采用串联导热率得到约 `0.757264`，原始输出为 `30.881014`，
  误差约 `30.123750 W/(m·K)`。
- 忽略基体导热、只取 `f*k_m`，误差约 `0.610460 W/(m·K)`。

不是因为这些公式常见就直接采用；报告保留了每例的替代公式误差。

## N 的输入解释与焊球输出计数差异

配套输入脚本用于识别所改参数，最终物性始终取原始 FloXML。
基线完整球阵列有 5×5 个球位；换预设的完整阵列从其 FloXML 中各轴球位数读取。
普通阵列 N=MD*ME；去球样本符合：

```text
N = MD*ME - (MD-MDp)*(ME-MEp)
```

选 No 时，N 直接取输入脚本的 `numberOfBondWiresNw`，该案例为 16。
启用空球位图的归档案例 N=0。

不要统一把输出焊球 cuboid 个数当成 N：

| 样本 | 物性吻合的 N | 实际输出球块数 |
| --- | ---: | ---: |
| staggeredMatrix=true（solderBalls 组件） | 25 | 13 |
| 去球 MDp=1、MEp=2 | 13 | 10 |
| 去球 MDp=3、MEp=2 | 19 | 16 |
| 上述 MDp/MEp 交换的两个样本 | 13 / 19 | 10 / 16 |
| 独立线数 No、Nw=16 | 16 | 25 |

这纠正了“选 Yes 后线数一定等于最终导出球块数量”的过宽表述。
其中交错/去球差异是归档输出自身的行为，本研究没有修改或解释成项目生成器行为。

## 范围限制与复现

- 76 例含重复物性状态，不代表 76 个独立体积分数或 760 次独立实验。
- 只验证本组 Gold + Typical Epoxy 的组分值；没有材料替换变参，不能宣称已验证任意材料。
- thermalDie 案例使用相同芯片 cuboid 长宽和 N=25 不能匹配该公式，因此明确排除，
  未把 actualDie 的输入解释强推到该分支。
- nonstandardOutline 和 Ignore 也单列排除；空球位图以外的自定义球位图不在证据范围。
- 这是既有归档数据复核，没有新运行 PACK 或导出模型，也没有验证温度场等价性。
- 原始 XML 保留本地，未纳入 Git；报告保存源文件哈希，变更归档后应重新执行。
