# IC 封装参数化模板库需求说明 -- PackStudio

## 1. 项目目标

参考并复刻 Flotherm PACK 的 UI 和建模逻辑，建立一个面向 IC 封装热仿真的参数化模板库。

该模板库通过引导式、参数化方式，快速生成典型 IC 封装的等效热分析模型，并通过生成的模型文件作为接口, 传递给后续的网格生成和数值求解模块。

## 2. 功能定位

模板库负责先进封装模型的定义与生成；下游软件负责网格划分、数值求解和边界条件设置。

主要功能包括：

- 提供经典 IC 封装结构模板；
- 使用 Wizard 界面，引导用户输入封装相关的几何参数/材料属性/热源，并根据输入参数自动生成封装模型；
- 支持八种常用封装外形；Bare Die 提供基线设置，其他七类封装提供原生预设参数；
- 在材料库中浏览材料，并为当前方案编辑材料属性；
- 输出可供后续网格生成和求解使用的指定模型文件格式。
- 在单一模型树中按父子节点检查模型，支持父节点折叠/展开、递归显示/隐藏以及一键全部折叠/展开；

下游模块职责，本项目不负责：

- 网格划分；
- 热场数值求解；
- 边界条件设置。

## 3. 模型表达方式

模型采用统一的笛卡尔坐标系。

每个几何实体包含：

- 空间位置；
- 几何尺寸；
- 材料属性；
- 源项信息；
- 所属封装结构类型。

多个矩形块及其布尔组合共同组成完整的 IC 封装热模型。

## 4. 输出格式

输出使用自定义 PackStudio XML，仅包含轴对齐长方体块、已计算材料物性和按块关联的体热源。内部网格参数保留，输出不包含网格、辐射、非物理区域或监视点。格式契约见 [PackStudio XML](../output_format/packstudio/README.md)。

## 5. 用户操作流程

```text
选择 IC 封装模板
        ↓
引导式输入模型参数
        ↓
生成笛卡尔坐标系下的矩形块模型，以及对应材料和热源
        ↓
输出指定的模型文件格式
```
