# 提交说明 — 2026-07-30

## 变更概述

将组件材料选择收进八类封装向导，以模板白名单约束材料适用范围，同时完善可编辑材料库、
组件/Layer 模型树显隐、属性栏裁切和输入范围说明。

## 变更详情

### 生产模板与校验

- 新增组件材料选择定义，八类模板显式声明组件组、步骤、默认材料和有限候选项。
- 后端拒绝未知组件组、白名单外材料和当前条件分支中未激活的材料绑定。
- 保持 BGA 动态焊料/空气表达与 Flip-chip 正交各向异性等效材料不受普通材料绑定覆盖。
- 拆分 Flip-chip 顶盖/TIM 和 QFN thermal land 结构组，使材料绑定语义单一。

### 向导与材料库

- 左侧对应组件步骤渲染材料选择；切换条件分支时清理已失效的材料覆盖。
- 右侧改为“材料库”，移除结构组绑定，支持浏览和编辑名称、颜色、三向导热率、密度和比热。
- 材料修改以稳定 ID 保存为当前方案覆盖值，不改写源码内置材料库。
- 恢复旧保存方案时过滤旧字段和任意材料绑定，避免迁移后无法生成。

### 模型检查与字段说明

- 模型树新增“组件层级 / Layer 层级”视图，父节点可递归显示或隐藏后代块。
- Layer 按矩形块完整 Z 区间组织，并保留原有单块右键操作。
- 属性栏切换步骤时回到顶部，并增加顶部留白，修复首个字段标签裁切。
- schema 明确返回上下限，前端把“验证区间”改为“允许范围”并解释其可信度边界。

### 文档与测试

- 新增 TASK8、ADR-0008，并更新 requirements、README 和长期计划。
- 后端新增全部材料候选实际应用、非法/未激活绑定拒绝和方案材料覆盖测试。
- 前端新增材料向导、允许范围、材料属性编辑和 Layer 显隐测试。
