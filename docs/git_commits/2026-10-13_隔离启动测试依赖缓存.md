## 变更详情

### 启动测试
- 临时开发项目没有 package.json，Vite 会向上找到仓库包目录，默认共用仓库 `node_modules/.vite`。
- 测试显式使用临时项目内的 `.vite`；退出时一起清理。
- 断言服务器使用临时缓存，且测试前后的真实开发缓存元数据相同，防止再次覆盖日常缓存。

### 等待提示
- 单次请求取消/超时显示“本次检查超过 2 秒，服务暂未响应；继续等待”。
- 沿异常链识别取消异常，兼容 PowerShell 5.1 与 7 的异常包装；其他错误保留实际原因。
- README 说明测试缓存隔离。

`bundling dependencies`，最终显示“开发模式前端已就绪”。等待发生在重新预打包期间，

日志本身未列出所有配置差异，不能据此排除其他正常的缓存失效因素。

本轮首次真实预打包约 39.8 秒；完成缓存后，再次运行完整启动测试及同一启动命令，

该成本未被消除；耗时受缓存与机器负载影响。
