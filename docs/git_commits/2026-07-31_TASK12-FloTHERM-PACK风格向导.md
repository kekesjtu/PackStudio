# 提交说明 — 2026-07-31

## 变更概述

参考已验证的 FloTHERM PACK 工作流，将八类封装的左侧引导栏改为中文组件步骤，并增加手写
标准尺寸预设与受控建模规则。

## 变更详情

### 模板契约与尺寸预设

- 为八类模板增加共 41 个生产代码内的 Footprint/芯片尺寸预设，选择后联动整体尺寸、阵列、
  引脚数量和间距，同时保留显式工程微调。
- 固定 `standard_outline` 与 `actual_type`，将其写入 schema 和模型元数据但不渲染单值控件。
- 生产运行继续不读取 `flotherm_pack_data`。

### 引导栏与建模约束

- 按封装类别重排概要、封装规格、基板、芯片、凸点、焊球、引线框和键合线等中文步骤。
- BGA 去球与中央焊球拆分为独立入口；只有 BGA 显示等效层/离散建模选择。
- Flip-chip bumps 与 Bare Die 可选 bumps 固定生成有厚度的正交各向异性等效层，不提供
  collapsed cuboid。
- QFP/SOIC 删除 exposed-pad UI 字段，改为可选的散热焊盘与焊料，并分别生成对应矩形块。

### 前端与测试

- 增加 Footprint 下拉显示名、即时联动、切换预设清理旧覆盖及手动微调保留逻辑。
- 拆分工作区导航和特殊页面组件，保持生产文件不超过 300 行。
- 新增预设、固定规则、QFP/SOIC 散热结构和凸点厚等效层回归测试。
