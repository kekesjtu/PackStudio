# 提交说明 — 2026-10-11

## 变更概述
将已实现封装参数接入完整 PACK 原生预设和分类材料库，统一封装命名并清理旧适配链路。

## 变更详情
### 默认值与材料
- 342 个原生预设按明确路径投影当前支持参数，缺失有效值时报错，不再继承旧 FloXML 初值。
- Flip Chip PBGA 基板厚度按原生值读取为 1.15 mm；Wirebond PBGA 按其原生两层规则读取。
- 131 个 PACK 材料按名称引用分类库，运行别名只保存名称和颜色，项目材料单独声明。
- 原生去球、中央球开关决定阵列布局；保留未启用参数编辑初值和适配范围审计。

### 界面与命名
- 八类显示名称和顺序与 PACK 对齐；模块、预设文件、API、模型及下载文件使用统一 ID。
- PQFP、SOP 增加原生 Package Type 与 Footprint 联动和后端组合校验。
- 保存空间升级至 v3，不迁移旧方案；删除旧模板别名路由。
- 原有 FloXML 对照使用明确历史输入和物性夹具，保持几何回归检查。

### 清理与文档
- 删除旧转录预设、根级材料副本、缺值继承配置、重复原生快照和被替代工具。
- 保留带版本校验的原生提取工具，直接读取 DES；生成和导出审计移至 docs/validation。
- 归档目录按统一封装 ID 重命名，更新索引、引用、需求和技术决策。
- 删除可访问的历史临时文件、字节码缓存及本轮测试、wheel 验证产物；保留依赖和已有发布产物。
