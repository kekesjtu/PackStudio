# 提交说明 — 2026-10-12

## 变更概述

减少通过 `start.ps1` 启动后首次进入页面的模板初始化开销，并缩小后端热重载监听范围。

## 变更详情

### 参数库与模板初始化

- 预设和材料读取只复制所需索引项；材料名称枚举只读取键，避免每个预设反复复制完整索引。
- 默认请求只复制目标字段，仍隔离可变返回值，保留路径、模式版本、材料引用和 SHA256 校验。
- Pydantic TypeAdapter 按类型复用，八类模板将已校验字段传给材料选项加载器，避免重复解析。
- 模板目录与单模板入口共用初始化锁，避免首次并发请求重复构建同一套模板。

### 启动与复测

- Uvicorn 仅监听 `src/packstudio` 和 `default_parameters`，包括参数 JSON 的热重载。
- `--reload-include=*.json` 使用单个参数，避免 Windows 将独立通配符展开成仓库文件名。
- 保留每次 `uv sync --locked`：实测同步仅约 3–4 ms，不是主要瓶颈。
- 新增 `tools/benchmark_startup.py`，模拟浏览器并发请求目录、schema、defaults、材料，然后生成默认模型。
- README 补充性能变化、监听范围及复测命令。

## 性能结果与限制

本机新 Python 进程中，优化前并发首次 API 请求耗时 **12.231 s**。优化后三次独立运行分别为
**1.401 / 1.399 / 1.392 s**，中位数 **1.399 s**，减少约 **88.6%**。默认模型生成约 **0.002 s**；
导入、首次 API 请求和生成合计约 **1.724–1.743 s**。

脚本优化前前后端健康检查与关闭合计约 2.8 s；主要改善来自健康检查之后的首次页面数据加载。
以上数据不含浏览器启动、Vite 模块加载、WebGL 渲染或操作系统磁盘冷缓存，不能等同于端到端页面启动时间。

完整回归使用仓库内临时目录绕过本机已有 pytest 临时目录的权限问题：
`uv run --locked pytest --basetemp tmp/pytest-startup-20261012 -o cache_dir=tmp/pytest-cache-startup --tb=short`。
25 项跳过项是需要显式启用的 PACK 原生探针。

实现依据：[Pydantic 校验器复用建议](https://pydantic.dev/docs/validation/2.10/concepts/performance/)、
[Python 缓存首次并发调用说明](https://docs.python.org/3/library/functools.html)。
