# 提交说明 — 2026-10-18

## 变更概述

把前端表单的字段标题、单位和输入框分开，并将整体视觉调整为更接近工业软件的紧凑、方正风格；四列工作区布局和响应式断点保持不变。

## 变更详情

### 主题与视觉基线（`industrialTheme.ts`、`styles.css`）

- 调深钢蓝色标题栏，统一冷灰工作区底色、方角、细边框和紧凑控件高度。
- 输入框改为白底内阴影、1px 边框、聚焦时 1px 强调色描边；按钮改为带轻微渐变的方正外观。
- 面板标题改为浅灰渐变栏 + 左侧强调色条，导航选中态使用左侧色条。
- 补充分隔条、滚动条、选项卡、标签、警告框、菜单和方形开关的统一样式。
- 修正标题栏 `Paper` 边框带来的 2px 页面溢出，使桌面端工作区正好铺满视口。

### 字段结构（新增 `ui/FieldShell.tsx`）

- 新增字段外壳组件：标题行（标题 + 可选单位）、控件、提示行分层排列。
- 数值输入、下拉选择、材料选择、导出格式、网格选项和材料库名称/颜色均改用该结构，标题不再嵌入输入框的边框。
- 数值输入右对齐并使用制表数字（tabular-nums），提示/范围文字位于输入框下方。
- 保留可访问名称：文本框通过 `htmlInput` 的 `aria-label`，MUI 下拉通过 `SelectDisplayProps` / 原生 `select` 的 `inputProps` 关联标题，避免只依赖视觉标签。

### 应用栏、模型树与检查器

- 应用栏模板选择器改为深色方角控件，修复原样式优先级导致的“深底暗字”不可读问题。
- 模型树的展开/折叠图标改为工业软件常用的 `+` / `−`，分组和模块行增加紧凑行距、等宽编号与选中色条。
- 材料库列表、材料属性块、检查器选项卡和只读属性块统一为方角、细边框、等宽数值外观。
