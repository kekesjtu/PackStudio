# 提交说明 — 2026-08-01

## 变更概述

废止 PTA 根级 Block Build Mode，将八类封装统一为带层内矩形布尔压缩的 Layer Mode。

## 变更详情

### PTA 层规划

- 新增顶层感知的层规划器，先验证连续 Z 堆叠。
- 仅第 1 个 `IsTopLayer=true` 层保留不同块高度；其余层严格切为与 Layer 等厚的片段。
- 根级 `Blocks` 固定为空，`UseBlockBuildMode=false`，旧模式元数据不再改变输出。

### 矩形布尔表达

- 将 Z 起点和厚度加入压缩兼容键，禁止跨不兼容挤出范围合并。
- 连续矩形合并为整体，孔洞优先表达为外包络加矩形减去空区。
- 保持逻辑源、材料、结构、父组和体热源密度隔离，并保留物理 cuboid 作为模型真值。

### 测试和文档

- 新增相邻矩形合并、顶层独立厚度、八类全 Layer Mode、非顶层等厚和逐材料体积测试。
- QFN 默认导出保持 7 个 Layer，层内 XML Block 从旧逐碎片路径的 3747 个降至 328 个。
- 更新需求、PTA 输出契约、长期计划、TASK13、ADR-0013，并标记 ADR-0011 已被取代。
