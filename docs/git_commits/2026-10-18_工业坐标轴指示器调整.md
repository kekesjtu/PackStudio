# 提交说明 — 2026-10-18

## 变更概述

用自绘的工业风格坐标轴指示器替换三维视口右下角原生的鲜艳圆形轴头，改为细轴线、箭头和深色方形轴标签。

## 变更详情

### 坐标轴指示器（新增 `IndustrialGizmo.tsx`）

- 轴线改为细圆柱，末端加小尺寸锥形箭头，不再使用粗色条。
- 配色改为低饱和的氧化红（X）、橄榄绿（Y）、钢蓝（Z），与整体工业灰蓝界面协调。
- 轴头改为扁平深色方形标签，带对应轴色描边和白色 X/Y/Z 字母；标签始终面向相机，旋转视角时仍可读。
- 增加中心轴毂和悬停放大效果；点击标签仍会像原控件一样把相机转到对应轴向。
- 指示器整体缩小并靠近视口右下角，隐藏负向轴，保持原有交互。

### 三维视口（`ModelPreview.tsx`）

- 移除 drei 的 `GizmoViewport` 和 `GizmoHelper` 直接引用，改为渲染 `IndustrialGizmo`。
- 模型、相机、轨道控制器和其他视口行为未改动。
