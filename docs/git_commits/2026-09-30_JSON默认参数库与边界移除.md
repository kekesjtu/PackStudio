## 变更详情

### 参数库与运行时
- 七个家族完整转录 342 份 .des，保留原始字符串、类型化值、源路径及 SHA-256。

- 删除冗余字段/Footprint/选材构造器和硬编码物性；保留既有几何算法和参数优先级。
- 版本、范围、预设目标及选材校验，缓存隔离，缺失/非法值无备用数值回退。
- setuptools wheel 和 PyInstaller 包含库；新增使用绝对路径的后端构建入口。

### 边界功能移除
- 删除向导入口、环境表单、请求 environment、自动 PCB/顶部边界及 PTA 默认对流。

- 旧保存参数恢复时移除 environment，其余配置保留；通用外部模型边界契约保留。
- 更新 exporter 回归，以显式外部边界继续验证通用导出能力。
