### 文件审计
- `tmp` 中的启动探测脚本、源码测试备份、CPU 采样、截图、请求记录和 pytest 输出
  均为此前调试或测试产生；保留 `tmp/startup` 服务日志，避免干扰正在运行的服务。

- `tools` 中的 PACK 提取、反汇编、参数审计与前端探针仍构成复核工具链，保留源码与参考证据。

### 清理入口
- 新增 `tools/clean_workspace.ps1`；支持 `-ListOnly`、`-WhatIf`，默认执行清理。
- 保留 Python 环境、Node 依赖、日常 Vite 缓存、生产前端 `dist`、服务日志。
- 删除前检查绝对路径属于当前仓库、目标和祖先路径不是重解析点，且不含 Git 跟踪文件。
- 文件被占用或权限不足时报告路径，以失败退出码结束；不改变权限或停止用户进程。
- README 说明清理范围和运行方法。
