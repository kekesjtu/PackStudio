# 提交说明 — 2026-10-12

## 变更概述

将一键启动默认前端切换为可缓存的生产构建，缩短从浏览器打开页面到完整四栏和三维视图出现的等待。

## 变更详情

### 启动模式与缓存

- 默认运行 `vite preview`，使用压缩和摇树优化后的前端，沿用 5173 端口及自定义 API 代理。
- 输入文件与产物内容 SHA256 校验：输入变化、缺失产物、损坏资源或无效缓存记录自动触发重建。
- 新增 `-Dev` 保留热更新模式；`-Setup` 在默认模式下强制重建。
- 后端就绪等待改为默认模板 schema，打开浏览器前完成模板初始化，只接受 HTTP 200。
- 缓存文件写入被忽略的 `dist/.packstudio-build.json`，仅在构建成功且生成 HTML 后更新。

### 依赖与文档

- MUI 控件按路径导入；主题 API 使用公开 styles 入口；drei 收窄到使用的五个控件。
- Vite 开发模式预热主入口，生产预览配置保留自定义后端代理。
- README 说明默认/开发模式、重建规则和旧服务需停止后重启的操作；新增 ADR-0023。
