# 提交说明 — 2026-10-11

## 变更概述

结合安装 `.des` 和原生逆向结果，将 342 个预设分别保存为可独立读取的 JSON，
并把 131 项材料按类别独立保存，由预设引用材料完整名称。

## 变更详情

### 预设文件

- `default_parameters/presets/` 按七个源家族分类，一预设一文件。
- 共 416 个分支：342 个默认分支，以及 Chip Array/WB 的 74 个四层分支。
- 保存向导选项、子类型、组开关、数值/枚举、完整顶盖子对象、金属表和对话框内容。
- 展开自动金属层深度、Chip Array 原生键合线计数、QFN getter 默认步数、
  leadframe 自动覆盖率；计算依据写入对应 JSON comment。
- 原生 WB 基板、过孔、线数与背面结构计算结果直接保存，并记录规则。
- 添加原生实现固定的 Silicon (Pure) 芯片材料引用。
- 原文全部字段与哈希仍保存于每个文件；无有效数值的字段明确区分为未启用、
  用户待填、可选材料未指定和 UI 动作，没有借用项目模板默认值填空。

### 分类材料库

- `default_parameters/materials/` 保存十类、131 项原生内建材料，名称为唯一引用键。
- 保存密度、比热、发射率、各向同性/正交/温度相关导热定义和原生完整存储。
- 不把各向同性材料未使用的 kx/ky/kz=0 当成三向零导热，不混用正交材料残留字段。
- 内建库提取不读写用户材料文件，构造期间的 FLOCENTRALDIR 环境值恢复。

### 读取、工具和分发

- 新增 PresetCatalog / MaterialCatalog 离线读取接口、名称解析、身份/哈希校验与深拷贝。
- 扩展原生提取器，核验七个 DLL 构建哈希，读取嵌套对象及有效 getter 返回值。
- `tools/extract_pack_catalog.py` 可全量重建两套库，不用 FloSCRIPT/FloXML 导出。
- wheel 增加全部分类目录；源码/EXE 的现有递归数据分发配置已经覆盖新文件。
- 更新参数库 README、项目结构、后续研究说明，保留第一轮研究的历史证据。

## 备注

本次完成“先保存完整默认参数并提供读取”的建库工作，当前建模选择器仍使用旧的
source_adapters；没有把研究参数自动映射到缩减后的几何模型。原始 `.des` 与安装 DLL
没有修改或复制。全部新库文件使用 UTF-8/LF，索引校验原始 JSON 字节。

完整性以原预设默认状态及其已提供四层选项为范围，不表示穷举 PACK 所有交互组合。
未赋值额定温度/功率是器件用户信息，未启用结构是无适用参数，均不伪造数值。
非均匀热源的非空 ABI 当前尚未支持，出现该情况提取器会报错，而非默默丢弃。
温度相关材料保留原生定义，本次没有新增求解器的温度评价/插值实现。

两条 Chip Array 的源列表含 48/80 个球位，但原生默认去球开关关闭时线数计数函数为
49/81。文件保留源列表、原生开关和函数结果；与现有项目显式列表策略的差异已写明，
未用名称数量覆盖原生结果。后续几何适配仍需单独核对，不能以保存/读取测试代替。

数据结构及使用方法详见 `docs/research/pack-preset-catalog.md`。
