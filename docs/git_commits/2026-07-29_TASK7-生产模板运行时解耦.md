# 提交说明 — 2026-07-29

## 变更概述

将八类封装从 `flotherm_pack_data` 运行时适配改为 PackStudio 手写生产模板，使软件能够
脱离全部参考资料独立生成、配置和导出模型。

## 变更详情

### 原生模板库

- 新增 `templates/package_library`，包含八个模板模块、显式字段定义、参数范围和条件联动。
- 为 Bare Die、两类 Flip-chip、两类 wire-bond BGA、QFN、QFP 和 SOIC 分别实现几何规则。
- 公共层只提供确定性矩形差集、BGA/Flip-chip 特殊层、内置材料、热源、边界和领域装配。
- schema 升级为 `packstudio.wizard/v2`，目录明确声明无需运行时参考数据。

### 特殊层和基准

- 只有 BGA 模板接受等效/离散配置，以及中央焊球和焊球去除。
- Flip-chip bumps + underfill 固定为有厚度正交各向异性等效层。
- Flip Chip CBGA 保持 5.3 mm BGA 包络、1.8 mm bump 包络和已复核层叠。
- 材料改用稳定 PackStudio ID 的内置定义，仍支持用户编辑和结构组绑定。

### API 与前端

- 主接口改为 `/api/templates/{template_id}/*` 和 `/api/templates/materials`。
- `/reference/*` 只保留隐藏兼容别名，内部调用同一生产生成器。
- 前端功能目录改为 `features/package-library`，保存键升级为 library v2。
- 删除运行时 repository、FloXML parser、variation patch、动态材料读取和旧场景转换器。

### 验证

- 新增阻断 `Path.read_text` 和 `lxml.etree.parse` 的独立运行测试；8 类生成/导出全部通过。
- 八类默认模型均无正体积重叠，八类 PTA XML 均可解析且不含网格实体或求解结果。
- 后端 76 项、前端 16 项测试通过；Ruff、ESLint 和生产构建通过。
