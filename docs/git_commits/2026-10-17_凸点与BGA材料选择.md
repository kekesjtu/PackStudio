# 提交说明 — 2026-10-17

## 变更概述
开放凸点焊料、underfill 与 BGA 焊料选择，并让当前选材和方案物性覆盖参与层材料计算。

## 变更详情
### 向导与默认参数
- 两类 Flip Chip 和 Bare Die 可选凸点增加独立焊料、underfill 选择；四类 BGA 模板增加焊料选择。
- 焊料候选取现有 `Alloys (Solders)` 分类，underfill 采用已采集 PACK 默认 `Others` 分类。
- 原生预设通过明确路径提供默认组分，Bare Die 使用项目默认；当前默认选材保持原值。
- 更新真实前端 schema 夹具，验证选材、切换 Footprint 和保存恢复。

### 生成与材料
- 在调用层构建器前统一解析预设默认与显式选材，底层验证工具复用同一解析方法。
- 凸点消费所选焊料与 underfill，BGA 消费所选焊料和静态空气，按当前物性重算等效材料。
- 离散中央与外围焊球使用当前焊料，去球区保持空气；显式等效材料物性覆盖保留最终优先级。
- 组分选择使用独立键，避免把整个等效层覆盖为单一组分；材料来源记录所用组分 ID。
- 重新生成完整预设审计报告，更新 README、参数库说明和 TASK31。
