# 提交说明 — 2026-10-18

## 变更概述

把焊球去除的显式去球输入从文本格式改为可点击的焊球矩阵，同时按开关状态收起相关控件、移除允许范围提示，并让数值输入在获得焦点时自动全选。

## 变更详情

### 焊球去除矩阵（新增 `SolderRemovalMatrix.tsx`、`solder-matrix.css`）

- 用阵列矩阵替代原来的“例如 0,0; 2,3”文本输入，矩阵行列来自模板中的 `bga.rows` / `bga.columns`（经 `valueFor` 解析覆盖值和封装预设）。
- 点击矩阵单元即可添加或取消 `omitted_cells`；选中的单元显示为红色叉号，标题行显示“已选 N 个”。
- 去球区覆盖的中心区域显示为斜纹且不可点击，避免与显式去球重复操作；图例区分可点击、显式去球、去球区覆盖三种状态。
- 行列编号从 0 开始，带行/列索引；矩阵超过面板高度时在容器内滚动，最大支持后端允许的 50 × 50。
- 单元按钮带完整中文 `aria-label`、`aria-pressed`，矩阵带 `group` 语义和操作提示。

### 焊球去除面板（`BgaConfigurationPanel.tsx`）

- “显式去球单元”矩阵及其标签只在“焊球去除”开启时渲染，关闭时整块消失，不再显示灰色禁用输入框。
- 删除原来的文本解析函数和输入框；关闭开关时仍会清空 `omitted_cells`。
- “去球区行数 / 列数”和中心焊球参数保持不变。

### 数值输入交互

- `NumberInput` 与向导数值字段在获得焦点时调用 `select()`，自动全选当前数值，便于直接输入替换。
- 该行为覆盖去球区行列、中央焊球行列、材料物性和模板数值参数。

### 提示清理（`WizardFields.tsx`）

- 移除页面顶部的“允许范围”是模板输入边界……的整块提示；字段下方的单行范围说明仍保留。
