# 提交说明 — 2026-10-01

## 变更概述

将全部 342 个 FloTHERM PACK 源预设接入 JSON 驱动的生产模板、规格选择器和导出流程。

## 变更详情

### 参数库与来源

- 7 类源全部可选，另保留 4 个 Bare Die 规格，总数 346；源字段及 .des 来源哈希保持原样。
- source_adapters.json 声明字段映射、派生规则、缺值继承、双侧 QFN 修正及固定核验基线标识。
- 七个默认基线保留原生导出对照；更改默认选择不会把新规格误标为已核验。
- adaptation_report.json 保存全部参数审计、源材料名、输入 JSON 哈希和 510 种配置的验收结果。
- JSON 统一 UTF-8/LF；修复 Windows CRLF 与 Git LF 转换导致文件校验不一致的问题。

### 几何与界面

- 正确转换 BGA 全填充行数、中央球和去球区；接入 Chip Array 的逐球坐标列表。
- 去球区行列为 0 时仅应用显式去球；关闭去除时清理对应源缺球列表。
- QFN_3X3_6 生成双侧六引脚，不生成空侧引脚及键合线；共面端点省略零高度垂直线块。
- UI 切换规格应用源布局，保留表达方式、独立顶部/通孔/散热焊盘开关、功率与有效用户选材。
- 保留全部既定 UI 功能、四区分区与工业软件风格；不恢复边界设置。
- 46 个名称球数冲突和 2 个区域奇偶不匹配均显式提示，不按名称猜测几何。

### 文档

- 更新 README、requirements、参数库说明、ADR18 与 TASK18。
- 增加可复现的全量适配/导出验收脚本。
